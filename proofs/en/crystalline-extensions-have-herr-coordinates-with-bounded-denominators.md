# Crystalline extensions have Herr coordinates with bounded denominators

[Chinese proof](../zh/%E4%B8%BA%E4%BB%80%E4%B9%88%E6%99%B6%E4%BD%93%E6%89%A9%E5%BC%A0%E7%9A%84%E4%B8%A4%E4%B8%AAHerr%E5%9D%90%E6%A0%87%E6%9C%89%E6%8C%87%E5%AE%9A%E5%88%86%E6%AF%8D.md)

Let $0\to T\xrightarrow\iota T'\xrightarrow q O\to0$ be exact in crystalline $O$-lattices, with trivial quotient. Use the Wach notation $A=\prod_iO[[U]],X,Q$ from the [kernel comparison](the-wach-kernel-is-the-intersection-with-the-etale-kernel.md). For each component $i$ assume all de Rham filtration jumps for $T[1/\ell]$ there are in $[-M_i,h_i]$ with $M_i,h_i\ge0$, and set $M=\max_i M_i$. Take $e\in N(O)$ fixed by $\varphi,\gamma$, and $x\in N(T')$ with $D(q)x=ae$, $a\in O$. Use the effective-parameter condition $(\gamma-1)N(T')\subset XN(T')$, with $X$ a unit in the étale ring. Then the [Herr coordinates of the extension](the-two-herr-differences-recover-the-extension-class.md) satisfy $Q^M y\in N(T)$ and $z\in XN(T)$.

**Proof.** The crystalline sequence gives a strict exact sequence of de Rham filtrations, and the trivial representation has only jump zero. Each window contains zero, so it bounds the jumps of $T'[1/\ell]$ as well. The [height argument](two-wach-heights-from-filtration-jumps.md) gives $Q^{M_i}\varphi(N(T')_{i-1})\subset N(T')_i$. Multiply by $Q^{M-M_i}$ and combine the components to conclude $Q^M\varphi(x)\in N(T')$, hence $Q^M(\varphi-1)x\in N(T')$. The two differences map to zero since $ae$ is fixed. Étale exactness therefore identifies the first as $D(\iota)y$. The kernel comparison gives $Q^M y\in N(T)$.

For the other coordinate write $(\gamma-1)x=Xw$ with $w\in N(T')$. In the quotient $X D(q)w=0$; cancel the unit $X$ to get $D(q)w=0$. Lift $w$ to $w_0$ in $D(T)$ by exactness. The kernel comparison puts $w_0$ in $N(T)$, so $z=Xw_0$. If $x$ is fixed by the tame subgroup $\Delta$, then both coordinates are fixed by commutation and injectivity. At a split prime the project compares the invariant parameter ideals, which agree up to units, to use these bounds in the invariant Herr complex.

`Q_pow_φ_mem` takes the maximum of the heights, and `core` uses the kernel for the two coordinates. The main crystalline-extension theorem uses the strict filtration sequence and the [effective-parameter congruence](cyclotomic-action-is-trivial-modulo-the-effective-parameter.md).
