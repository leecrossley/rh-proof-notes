# A finite coefficient request supplies all the congruence objects

[Chinese proof](../zh/%E6%80%8E%E6%A0%B7%E8%AE%A9%E6%89%A9%E5%A4%A7%E7%9A%84%E7%B3%BB%E6%95%B0%E7%8E%AF%E5%90%8C%E6%97%B6%E5%AE%B9%E7%BA%B3%E5%90%84%E5%A4%84%E7%9A%84%E5%90%8C%E4%BD%99%E5%AF%B9%E8%B1%A1.md)

Fix the project automorphic inputs, arithmetic columns and underlying place set $\mathcal W$. A request is a family of finite subsets $b_w\subset\mathbb C$, $w\in\mathcal W$. The predicate `Built(b,L)` says the local system $L$ contains the requested elements in the localized coefficient fraction fields and supplies the matched arithmetic and automorphic spectral data `NdSpec` and `AutSpec` with semisimple residual representations. Write $\operatorname{EvO}(P)$ if some request forces $P$ for every construction satisfying it.

Assume `BuiltEx`, that each finite request has a construction. Assume also the coefficient comparison: for any baseline construction $L_0$, some request $b^{(1)}$ guarantees that for each local index $i_1$ of every $L_1$ satisfying it, one can find an index $i_0$ of $L_0$ over the same place with compatible extension `LocExt`. Increasing a request preserves the implications of a smaller one. The comparison uses the project's Hecke integrality, splitting at specified places, and automorphic matching. [Construction definition](https://github.com/tamnd/riemann-lean/blob/9110120cdc195ee8d2fb08d2adac8b1747912d8f/lean/src/Development/AbelianVarietyTheory/Definitions/NonGaloisDescent/BuiltEx.lean#L13) · [Coefficient comparison](https://github.com/tamnd/riemann-lean/blob/9110120cdc195ee8d2fb08d2adac8b1747912d8f/lean/src/Development/AbelianVarietyTheory/Proofs/InertiaEigenvalues/SideEigenIntegralityStatement.lean#L9)

**Proposition.** With the project automorphic and Chebotarev inputs, assume $\operatorname{EvO}(\mathrm{Conclusion41}\land\mathrm{OSplit}\land\forall i\,\mathrm{ZDecomp}_i)$, respectively giving the matching Hecke representations and local properties, the coefficient splitting, and the prescribed character decompositions at good points. Then $\operatorname{EvO}(\mathrm{TakenAll})$: every local index with a `Live` witness of absolute irreducibility for the residual complement admits matching full and complement families with [`TakenWild`](transferring-congruence-data-with-the-same-wild-inertia.md).

## The baseline finite request

Take a request witnessing the joint assumptions and use `BuiltEx` to choose a baseline $L_0$ satisfying it. At any `Live` index $i_0$ take the automorphic construction of the Hecke-matching family with the specified good-point decompositions and absolutely irreducible residual complements. Choose a [cyclotomic inertia element](making-cyclotomic-inertia-wild.md) for this index, usable at every good point $\pi$. For each such $\pi$, the [orthogonal projections](orthogonal-projections-from-an-integral-representation.md) and [outside-point perturbation](separating-corner-roots-away-from-the-good-point.md) give a corner polynomial $P_{\pi,x}$, monic of degree $t$ with distinct roots for each evaluation $x$. Form the finite set $S_0(i_0)$ of all complex roots over these finitely many $x,\pi$ via the project's coefficient embeddings. This is a set satisfying `Chosen` at that index. Use the empty set at indices without a witness.

## Every later construction has the prescribed roots

Let $b^{(1)}$ be the coefficient-comparison request for $L_0$. Enlarge it at each underlying place $w$ by the union of $S_0(i_0)$ over the baseline indices there. The project indexes this union by finitely many layers $0\le j\le R.m$, so the new request is still finite at each place. For any $L_1$ satisfying it and any `Live` index $i_1$, use `LocExt` to find $i_0$ of $L_0$ over the same $w$. The [residual descent](descending-residual-absolute-irreducibility.md) shows this $i_0$ has `Live`, so its requested root set is the one constructed from genuine baseline data.

Use the old coefficient ring as $A$ in `TakenWild`. Pull its function ring, representations, projections and corners back by the index and Galois identifications. They retain their identities over $A$. Extending scalars to the new ring preserves the Frobenius matching and gives `GoodR`. The new Hecke function ring is the new coefficient span of the old one since it is generated by the same Hecke values. Every baseline root is in the request and therefore has a preimage in the new localized coefficient field. The product of the corresponding monic factors equals the corner polynomial since it does after the injective embedding into $\mathbb C$. Under the Galois isomorphism the selected element retains its inertia, wild inertia and cyclotomic conditions. These are the required `TakenWild` data at $i_1$. The choice of $i_1$ was arbitrary with a witness, so the final request forces `TakenAll`.
