# Point kits on the host windows give a family design

[Proof catalogue](../../PROOFS.en.md) · [Reading and review status](../../STATUS.md)

Fix $\lambda>1$, a requested host property $G$, and a function $c_T(\varepsilon,y)$ for the word-prime upper constant. A permitted scale has $x>1$, $0<\varepsilon<1/52$ and a common host parameter $J$. The hypothesis `HostExW` says that for each such $\varepsilon$ there are fixed $C_{T2},C_8,C_5,c_6,C_b,x_0$, with $C_8\ge1$ and $C_5,c_6,C_b>0$, and a set of allowed scales with $\lambda$-windows. At every allowed $x\ge x_0$ it supplies ranks, a host field and auxiliary prime data satisfying the host conditions and $G$. The $\lambda$-windows are those in `Scales`. In particular the allowed $x$ are unbounded, so restricting to any sufficiently large tail preserves the window property.

Fix a point predicate $Q(\kappa,D,O)$ on the arithmetic and automorphic objects, where $\kappa$ is the positive parameter record in [the class selection](one-family-class-supports-all-the-linked-bundle-tests.md). Assume `MinkDiv`, the auxiliary denominator existence used in the design, and the eventual recursion `RecExP` for $Q$ with the tuple, twist and lattice conditions `QD`. The latter means the following. For each sufficiently small positive $\varepsilon$, after choosing the large parameter requirements in the order of `ParEv`, there are $c_s>0,x_0$ such that for each allowed large scale $s$, each good preliminary word and weight record, one may choose positive factors $d_u,D_*$ for its words. With $f,k,m$ the associated ranks and $\Gamma$ the prescribed common adjustment, these factors satisfy
$$
c_s m s.L\le
\log\!\left((D_*/d_u)^{1/(fk)}\Gamma^{-2/(fk)}\right)
\quad\text{for every word }u.
$$
For *any* subsequent level extension with precisely these factors and adjustment, the recursion produces a compatible layered object over the preliminary record with the required good weight, size and twist data. On every resulting point with the given scale, good weights, size data and canonical instance, it satisfies $Q$ and `QD`. The construction of this recursion for the selected predicate is an upstream input.

Then `recS` gives `ExD` for the class determined by $Q$. Explicitly, there is a positive upper bound for $\varepsilon$ such that for each $0<\varepsilon$ up to that bound and each transported large-constant requirement, one can choose a family in the class of $Q$, with good twists, meeting $G$ at every point and preserving the $\lambda$-windows. The design supplies nonnegative code exponent $C_H$, positive $C_5,C_b$, and the eventual thick-set, tame, character, code and divisibility estimates of `DesignChoices`. Its word-code constant is $3$, its row parameter is $C_{YL}=9$, and it has $C_{Tu}\ge c_T(\varepsilon,C_{YL})$.

### Supply individual objects at the chosen host

The least prime in a progression bound gives the auxiliary prime required by the host. Apply it to the given host field to adjoin the canonical $q_0$ with the required congruence and exclusions. The positive height lower bound in the recursion then permits the word primes to be chosen in their short relative intervals, using the level-prime theorem. Applied to the recursion, [the object existence theorem](choosing-the-window-primes-completes-each-arithmetic-object.md) gives, for every admissible host and weight choice, every admissible injective code, and every weight label $u_0<n$, a point at the given scale with the prescribed host, weights, code and label. It also supplies an arithmetic instance of that object and the point property $Q$ with the twist and lattice requirements. To get existence without the extra predicate, simply forget $Q$ on these same objects.

Use this weakened existence first with the host scale requirement to obtain weights satisfying the stronger window inequalities and the wall condition. The source `hostWW` uses preliminary weight windows and a family assembled from such unqualified points. On that family the eventual wall theorem yields weight data at one point at every allowed late scale. Recovering the weights from that point preserves the host and $G$. This first family is used to prove the host-and-weight existence statement. The subsequent construction uses that statement on the same allowed scale set.

### Group the objects into one kit for each scale

Make the eventual hypotheses for the host and the objects simultaneous by taking the minimum of the two $\varepsilon$-ranges, the supremum of the large-constant requirements, and maxima of the lower thresholds in the order they are chosen. Include the thresholds for the small-prime bound and for injective codes. For a late scale $x$, choose the host and weights with the strengthened windows. The code has
$$
M=\left\lceil 3\,\exp(C_\Gamma m^5 f x^\varepsilon)^2\,x^{C_F}\right\rceil
$$
words embedded injectively in the $(k-2)$-bit vectors. This is the size required in the object existence hypothesis. Apply that hypothesis once for every $u_0=0,\ldots,n-1$, with the same host, weights and code.

These points form a kit. Its index set is the $n$ weight labels. Any two points from the prescribed host and weights have the same ranks, host prime data and other shared numerical inputs. Each word is identified with its common code, so comparisons between points can use the same bit vector. Every weight label has a point by construction. The point duties, wall and thickness, the estimates for bad characters and quadratic progressions, and $G$ are inherited from the common host and the individual object hypotheses. In particular choosing many weight labels has kept the same choices that the estimates compare.

### Assemble the family while preserving the windows

Choose a standard constant record $C$ above both the transported requirement and the one for the kit. In choosing it include $c_T(\varepsilon,9)$ as a lower requirement on its word-prime constant. Combine the two lower thresholds on $c_D$, then those on $c_h$, from the kit and the independent numerical-row theorem. Finally use a scale threshold $x_1>1$ beyond both applicable numerical and kit thresholds. At each allowed scale $x>x_1$, choose its kit and the numerical row data for each member. All hypotheses of these results hold at the same $x$ and $C,c_D,c_h$.

To make a family defined for every real $x$, choose one allowed scale $y\ge x_1$ as a default, using unboundedness. Use the kit at $x$ if $x>x_1$ is allowed, and the kit at $y$ otherwise. In the family take the indices $I(x)$ to be the kit indices when $x\le x_1$ or $x$ is allowed, and the empty set for $x>x_1$ outside the allowed set. The default supplies the required nonempty indices at zero. For $x>x_1$, every extant index comes from the actual $x$-kit. Thus the family's scale has $x$, $\varepsilon$ and the common $J$ as specified. Every allowed late $x$ still has nonempty indices, so the original windows are preserved. The shared parameters and pointwise estimates of the kits carry to this family, and every statement eventually in $x$ may use a threshold at least $x_1+1$.

The numerical data give the fixed parameters and rank windows of the family, in particular $C_{YL}=9$. The kit estimates give the thick set, the auxiliary prime condition, the bad-character and quadratic-progression rows, the two character-box tests, and the tame and twist conditions. The point divisibility clauses give the eventual choice of $D^\Gamma$ under `MinkDiv`. The ceiling defining $M$ is at most its argument plus $1$, giving the word-code upper bound with $C_H=C_F$. Finally change the recorded upper constant to $c_T(\varepsilon,9)$ by `setTu`. The chosen largeness requirement was imposed with this threshold, and none of the point data, windows or class membership depends on the altered entry. Since $C_{YL}=9$, the desired inequality $c_T(\varepsilon,C_{YL})\le C_{Tu}$ is an equality. This is the output of `designS` and hence of `recS`.
