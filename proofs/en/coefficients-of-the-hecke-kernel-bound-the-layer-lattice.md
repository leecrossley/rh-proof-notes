# Coefficients of the Hecke kernel bound the layer lattice

[Proof catalogue](../../PROOFS.en.md) · [Reading and review status](../../STATUS.md)

Fix a layer $j<m$ of an admitted local system, with coefficient field $K$, integer ring $O$, normalized prime valuation $v(p)=1$ and uniformizer $\varpi$ of valuation $1/e$. At a lattice tuple $\Lambda$ in layer $j+1$ let $W(\Lambda)$ be its value lattice. An integral function at this layer is equivariant under the level group with the specified character, vanishes on tuples outside the lattice domain, and has all its values in $W(\Lambda)$. Fix a list of distinct components and indices $0\le i_v\le r$, zero outside the list. Suppose the weighted cofactor coefficients in the corresponding Hecke-neighbor frames have valuation at least $g$ for every pair of source and target lattice tuples and every frame allowed by the local system. Under the admitted class-kernel, frame and descent laws, the product of the normalized Hecke operators following $K_j$ takes an integral input into the layer $j+1$ lattice multiplied by $\varpi^{\lceil e(g-d_j)\rceil}$. Here $d_j$ bounds the $p$-valuation of every class stabilizer weight. At an output tuple $\Lambda$, the successive neighbor operators sum over tuples $\Lambda'$ that differ from it by the prescribed index at each selected component. Index zero leaves that component fixed. The set of neighbors at positive index is finite, since it is determined by subspaces of a finite residue vector space. The normalizing $p$-powers multiply over components. For each $\Lambda'$ the corresponding value of $K_jF$ is a finite class sum. Each summand is a kernel value on a source representative, with scalar $c_K/w$, where $c_K$ is integral and the weight $w$ is a positive integer with $v_p(w)\le d_j$. The same description includes the final layer, which can have an additional finite sum within each class. Use the admitted Hecke-frame law for the pair $\Lambda,\Lambda'$. In this frame the normalized derivative cofactors are the entries testing whether the kernel output in $\Lambda'$, after the normalizing $p$-powers, belongs to the value lattice at $\Lambda$. The hypothesis on those entries therefore gives valuation $g$ on each normalized kernel value of an integral source vector, in the extension field used for evaluation. Multiplication by $c_K/w$ costs at most $d_j$. Summing over classes and neighbors preserves $g-d_j$, and the admitted lattice comparison descends that lower bound to the value lattice over $O$. The original function is equivariant and the neighbor operation preserves that property: a level element permutes the neighbors by its action on lattices and takes their values to the same character times the induced value action. It also preserves vanishing on nonlattice tuples. Thus dividing the resulting function by the asserted uniformizer power gives an integral function on the entire layer. When the available component bounds are real $g_v$ and the [coefficient theorem](integral-parameter-monomials-separate-the-cofactors-at-all-places.md) is stated for rational component bounds, take any $g'<\sum_v g_v$. Finitely many rational bounds $q_v\le g_v$ can be chosen with $\sum_v q_v\ge g'$, by taking each one within $(\sum_v g_v-g')/(|V|+1)$ of $g_v$. If the component set is empty the sum is zero and already rational. Apply the class-kernel argument at $g'$. Choose $g'$ sufficiently close to $\sum_v g_v$ from below that the ceiling $\lceil e(g'-d_j)\rceil$ is unchanged from $\lceil e(\sum_v g_v-d_j)\rceil$. This is possible because an integer ceiling is constant immediately to the left of every point in its $n$-th interval $(n-1,n]$. The result is the floor at the exact real exponent.
