# The period bound at each finite place

[Proof catalogue](../../PROOFS.en.md) · [Reading and review status](../../STATUS.md)

Work with the row $D$, its size data $L$, and the chosen base and twisted column family. Put $\mu_w=\muAt(w)$, the tuple prescribed at the finite place $w$, and let $e_w=v_w(p)$ for $p$ below $w$. The prescribed numerical period budget is $g_{u,w}=L.\mathrm{sg}(u,w)$. The statement `adm2` says that, for each word $u$, place $w$, $\phi$ in the input lattice $L.\mathrm{NuLat}(u)$, and each $F$ both integral in the test module for $\mu_w$ and in $V^0(\mu_w)$, the column period $P_{u,\mu_w}(\phi,F)$ is a value in the common coefficient field $K$ with
$$
v_w(P_{u,\mu_w}(\phi,F))\ge\lfloor e_w g_{u,w}\rfloor.
\tag{1}
$$
As usual set $v_w(0)=+\infty$. The proof first obtains the unrounded bound $v_w(P)\ge e_w g_{u,w}$. The following argument uses the local source-lattice comparisons, the class-period and point-integrality inputs of [the terminal column calculation](the-last-column-lattice-controls-the-period.md), and the three column and period estimates described in the cases below. In the row the tuple $\mu_w$ is used and its tuple-prime set omits $p$.

If $p$ is the word prime $T_u$, the input comparison places the image of $\phi$ in the localized word-prime lattice. The [base and twisted estimates at $T_u$](commuting-the-hecke-product-through-the-column-chain.md) give the full column bound $s=-m\,\mathrm{EatT}(u,w)$, where $m$ is the number of lifts. The stabilizer denominator $\mathrm{DGam}$ is coprime to $T_u$, so the terminal period formula incurs no loss. The prescribed budget at this place is precisely $-m\,\mathrm{EatT}(u,w)$, proving the unrounded inequality.

If $p\ne T_u$ is one of the two auxiliary primes $g_i$, use the [separate period estimate for all used tuples at that prime](the-auxiliary-prime-period-loses-the-product-of-layer-multipliers.md). It gives the normalized valuation $-\sum_{j=1}^m v_{\mathrm{NN}}(i,u,j,w)-C_1\,\mathrm{errC}$ as a lower bound on the period for vectors in the ramified base lattice. The size comparison `SgAtG` makes the prescribed $\sum_j(L.F(j,w)-L.E(u,j,w))=g_{u,w}$ at most this number. The input lattice comparison says that $\phi$ belongs to that base lattice after localization at $w$, so there is an integral scalar $b$ outside the prime ideal with $b\phi$ in the global lattice. Apply the estimate to $b\phi$. The period is linear in $\phi$, and $b$ has valuation zero, so division by $b$ preserves the inequality and the field of definition.

Suppose $p$ is neither the word prime nor an auxiliary prime. The lattice inclusion appropriate at $w$ places the input in one of two local submodules, according as the set of eligible orbit contributions is empty or nonempty. If it is empty, the input lies in the localized ramified lattice. Otherwise the row has a local model and the comparison called `NuServedDef` places the input in the localized submodule served by that model. The global column estimate `Conclusion1` applies in both cases. For its layer $j$ the numerical gain on the chosen lattice is at least the gain budget included in $g_{u,w}$, by the fill comparison. The estimate gives a valuation at least
$$
s=g_{u,w}+v_p(\mathrm{DGam}).
$$
Here the last term comes from taking the first-step option $\mathrm{sp}=1$, and $g_{u,w}$ uses the specified value, error and gain terms at this place. Applying the terminal period bound removes exactly $v_p(\mathrm{DGam})$, leaving the required $g_{u,w}$.

These cases exhaust the finite places. Multiplying the normalized valuations by $e_w$ and replacing the unrounded right side by its floor proves (1). The family statement is obtained by taking a common threshold in the size parameter so that the point, class-period, column and lattice comparison hypotheses all hold in the same row. In the source `famU` there are separate thresholds for the base and twisted point and period data, the served column estimates, the word-prime and auxiliary-prime estimates, and stabilizer coprimality. Their maximum, enlarged by the explicit threshold ensuring $x^{\mathrm{ez}/5}\ge3$, preserves each eventual assertion. The same argument also gives the auxiliary assertion `adm12` off the word prime on the ramified lattice, using only the value minus error sum and no additional gain.
