# 上同调长度怎样控制局部整除损失

## 第 1 节 · 命题 · 从上同调界到局部损失

窗口长度上界本身只说某些伽罗瓦上同调群小。要使它影响素数计数，还要知道这些群的长度出现在哪一个不等式里。本篇翻译 `divinN_of_hypV`，它把长度放进一个局部整除损失的上界，为后面的格和计数估计提供输入。[长度上界的数学内容](%E4%B8%8A%E5%90%8C%E8%B0%83%E9%95%BF%E5%BA%A6%E6%80%8E%E6%A0%B7%E5%BE%97%E5%88%B0%E5%85%B1%E5%90%8C%E7%AA%97%E5%8F%A3.md)

固定实数 `ε>0` 和满足项目尺度条件的族 `F`（`FamP ε`）。每个实数 `x` 有指标集 `I(x)`，每个 `i∈I(x)` 给出一份局部数域与秩数据 `D=D(x,i)`，以及对应的尺度和计数数据 `L=L(x,i)`。对充分大的 `x`，`L` 中的尺度正是 `x,ε`。后面各个量都允许依赖于 `(x,i)`，共同常数与阈值除外。

从数据中取宿主数域 `E`、长度截断 `t`、正整数因子 `f≥1`、提升指标的个数 `m≥0`、目标秩 `D₀≥0`，以及每个 `1≤j≤m` 所用的秩 `d(j)≥0`。置 `y=x^{ε}`、`b=e^{y}`、`B₀=fmby`。另有一个非负的尺寸量 `N_{c}`，由秩预算、厚点个数和尺度给出。在这个推理中只使用它非负。

要控制的量为 `A(j)=∑_{w∈S，μ(w)≠μ₀}λ(w)e(w)η(j,w)`（`etaSum`）。这里 `S` 是该份数据记录的有限处集，`μ(w)` 是局部标签，`μ₀` 是参照标签，`λ(w)` 是该处的权重，`e(w)` 是分歧指数，`η(j,w)` 则是第 `j` 个提升在该处的局部指标。这个和只累加局部标签偏离参照值的项。

**定理。** 假设本篇第 2 节的三个条件成立，则存在共同常数 `C′` 和共同阈值 `x₀`，使每个 `x≥x₀`、每个 `i∈I(x)` 及每个整数 `1≤j≤m` 都满足

```text
A(j)≤D₀ C′ x^{ε}(B₀+N_{c}).
```

## 第 2 节 · 准确列出三个输入

为写出局部比较，沿用上同调长度 `l(E,p,e)`，即用圆分特征的 `−e` 次幂作扭曲后的局部化核之长度。`D` 自带一套允许的局部化数据，以下取这一套。工程允许数值表另行记录长度 `λ_{p,e}`，并在实际长度有限时要求表与实际值相等（`D.nd.sha_eq`）。定义 `v(p)=(log p)∑_{1≤e<t}λ_{p,e}`，非素数的项记为 0。

**一、长度界（`HypV`）。** 存在 `x_{V}`，对所有 `x≥x_{V}` 和 `i∈I(x)`，在数域 `E` 上有 `VVle(E,t,√b)`。也就是说，对每套允许的局部化数据，每个素数 `p` 和 `1≤e<t` 的实际长度有限，而且任意有限素数集 `S′` 上的加权总长度都不超过 `√b`。

**二、局部比较（`LinkN`）。** 存在实常数 `C` 和阈值 `x_{N}`，对所有 `x≥x_{N}` 和 `i∈I(x)`，只要 `D` 自带的局部化数据对所有素数和 `1≤e<t` 都给出有限长度，就有如下蕴含。若级数 `∑_{p}v(p)` 收敛，则对每个整数 `1≤j≤m`，

```text
A(j)≤d(j)[C(fmby²+(log x)²N_{c})+∑_{p}v(p)]. (1)
```

这里的有限性条件在 Lean 命名为 `ShaFinOdd`，定义实际量化全部素数。在此证明中，局部指标与上同调群的关键比较由（1）提供。

**三、小层的秩等式（`SmallLevelRankEq`）。** 存在阈值 `x_{R}`，对所有 `x≥x_{R}`、`i∈I(x)` 和 `1≤j≤m`，有 `d(j)=D₀`。

## 第 3 节 · 长度怎样进入不等式？

固定一个足够大的 `x` 和 `i∈I(x)`。在条件一中选 `D` 自带的一套局部化数据，得到全部所需的有限性。因而长度记录等于实际值，有

```text
v(p)=(log p)∑_{1≤e<t}l(E,p,e)≥0.
```

条件一又给出对任意有限素数集 `S′`，`∑_{p∈S′}v(p)≤√b`。按照素数大小排列，部分和单调递增且有上界，所以级数收敛，和记作 `V≤√b`。这就满足了（1）要求的两个先决条件。

现在取 `1≤j≤m`。有 `f,m,y≥1`，于是 `b≥1` 和 `b≤B₀`。再由 `N_{c}≥0` 得

```text
V≤√b≤b≤B₀≤y(B₀+N_{c}).
```

由于 `log x=o(x^{ε/2})`，存在只依赖 `ε` 的阈值，使 `(log x)²≤y`。变量代换 `x=e^{u}` 后，上述小量关系就是 `u/e^{εu/2}→0`。因此 `fmby²=yB₀`，且 `(log x)²N_{c}≤yN_{c}`。这两项均非负，把（1）中的 `C` 放大成 `|C|` 可得

```text
A(j)≤d(j)[|C|y(B₀+N_{c})+V]≤D₀(|C|+1)y(B₀+N_{c}).
```

最后使用了秩等式。取 `C′=|C|+1`，并把共同阈值取成三条假设的阈值、对数估计的阈值和尺度一致的阈值的最大值。它不依赖 `i` 或 `j`，所以结论同时覆盖所有候选数据和提升指标。
