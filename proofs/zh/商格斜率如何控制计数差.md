# 商格斜率如何控制计数差？

## 第 1 节 · 黎曼猜想 · 逐点算术估计的输入

在平移平均的证明中，关键输入是对每个平移的计数差给出统一上界。本篇沿 `Deduction.ch_top` 展开这个输入如何从一组斜率和尺度不等式得到。先用商格斜率控制计数量，再解释为什么误差最终只损失 `e_{div}+e_{loss}+3` 个 `ε`。[计数差在下一步的用途](%E5%B9%B3%E7%A7%BB%E5%B9%B3%E5%9D%87%E5%A6%82%E4%BD%95%E7%BB%99%E5%87%BA%E7%B4%A0%E6%95%B0%E5%92%8C%E7%9A%84%E9%80%90%E7%82%B9%E4%BC%B0%E8%AE%A1.md)

### 输入中的对象

沿用前两篇的有限群 `H`、局部数据 `D`、`ℓ`、`N`、`T,T₂`、`a(t)` 与 `w_{h,j}`，以及计数差 `gap(h)`。令 `n=|H|`、`n_{T}=|T|`、`n₂=|T₂|`、`f=|Φ|=2n`。本篇主要用到另一份数值数据（`WeightedMeanData.Data`）。它含有限指标集 `U`，映射 `tr:U→H`，及对每个 `u∈U` 的有限非空指标集 `W(u)`。每个 `v∈W(u)` 对应同一平移下的一个局部对象。斜率输入是每个对象附带的实数，例如 `μ_{M},μ_{M}^{max},μ_{N},μ_{N}^{max}`。以下推理只用这些数的关系。

数据有整数 `m,f`、实数尺度 `x,ε,a_{E},b,b′,k,L,L_{a},B₀,N_{c}`，还有实数 `v₀,ℓ_g,γ,λ_{L}`。用 `Γ` 表示整组系数，包含 `c_{div},e_{div},c_{E},c_{H},c_{count},c_{slope},c_{1},c_{loss},e_{loss},c_{HH}`。另给定实数 `X″,e_{K},K`。原文用两个双射 `Top≃T` 和 `{1,…,f}≃Φ` 来索引。我们按双射改用 `t∈T,ρ∈Φ` 作为数值数据的下标。

数据中的尺度 `a_{t}` 和权重 `w_{u,j,ρ}` 必须满足 `a_{t}=a(t)`、`w_{u,j,ρ}=w_{tr(u),j}(ρ)`。此外 `γ=γ_{E}`、`λ_{L}=Re ℓ(c)`（`c(i,j,h)=(-1)^{i}`），且 `ASK(u)` 等于该平移上所有计数 `A_{t}` 的和。这些等式就是 `IdentU`。定义 `S_{a}=∑_{t∈T}a_{t}`，以及

```text
W_{log}(u)=∑_{j=1}^{m} f^{−1}∑_{ρ∈Φ}log w_{u,j,ρ},
Main(u)=m∑_{t∈T} a_{t}(log a_{t}−1−γ+λ_{L})−S_{a} W_{log}(u).
```

若 `a_{t}=0`，约定 `a_{t} log a_{t}=0`。由上述识别，`Main(u)` 正是该平移上所有主项的实部之和。因此

```text
gap(tr(u))=ASK(u)−Main(u). （1）
```

**要证的上界。** 对每组上述数据，若第 2、3 节的斜率条件以及第 5 节的尺度、阈值条件都成立，则对所有 `u∈U` 有

```text
gap(tr(u)) ≤ x^{(e_{div}+e_{loss}+3)ε} B_{E},
```

其中 `B_{E}=n_{T}a_{E}(1+m²/k)+m[2nmbx^{ε}+n₂kbx^{ε}/(n²x^{−ε})]`。

## 第 2 节 · 对每个局部对象有哪些估计？

以下条件在数值数据的每个 `u∈U` 与每个 `v∈W(u)` 上成立。在公式中省略固定的 `u`，把局部量写成 `d_{v},T_{v},h_{v},μ_{M}(v),μ_{N}(v)` 等，把只依赖 `u` 的量写成 `G_{a},F_{o},I_{O},μ_{CC},μ^{min}_{CC}` 等。`E_{v}` 是数据中 `m` 个指数比较项 `E_{v,j}` 的和。

**基本符号条件（`HidaSetting`）。** `x,b,k,v₀>0`，`f>0`，`a_{E},b′≥0`，每个 `a_{t}≥0`、`w_{u,j,ρ}>0`、`d_{v},T_{v}>0`。有 `μ_{N}(v)≤μ_{N}^{max}(v)`、`c₁≥0`、`δ̄<1`、`η̄≥0`、`0≤ē≤1/4`。`d_{v}` 用于归一化平均 `⟨Z⟩=∑_{v} d_{v} Z(v)/∑_{v} d_{v}`。

为写出其余输入，定义

```text
D_{0}=m∑_{t∈T}a_{t}[log a_{t}−1−γ−log(π/v₀)+λ_{L}],
D_{1}=c_{div}[n_{T}a_{E} L_{a} + m(B₀+N_{c})x^{e_{div}ε}],
S_{0}=c_{slope}n_{T}a_{E} L_{a}, q=m/k, J_{0}=c_{count}L_{a}(1+m²/k),
Λ_{5}=W_{log}(u)+m log(v₀/π)+mℓ_g−J_{0}.
```

**整除性（`DIV`）。** `μ_{CC}+h_{v}−F_{o}≤D_{0}−S_{a} log T_{v}+D_{1}`。

**指数和高度比较（`EComp5`、`HComp`）。** 对任意 `v,v′∈W(u)`，

```text
|E_{v}−mS_{a}ℓ_g|≤m c_{E} B₀,
|(h_{v}+S_{a} log T_{v})−(h_{v′}+S_{a} log T_{v′})|≤c_{H}(n_{T} a_{E} L_{a}+mB₀).
```

**计数尺度（`Count5`）及底格斜率（`Slopes`）。** 对任意 `v,v′`，

```text
Λ_{5}≤log T_{v}≤c_{count} m L, |log T_{v}−log T_{v′}|≤c_{count}log k,
μ_{M}(v)≥−S_{0}(1+q), μ_{M}^{max}(v)≤S_{0}.
```

**商格斜率（`QuotientSlopeBoundsWith`）。** 定义 `L_{5}(v)=c₁ I_{O}+c₁n_{T}m(a_{E}/k+b′)log T_{v}+c₁X″+1`。要求

```text
μ_{N}^{max}(v)≤μ_{M}^{max}(v)+G_{a}+F_{o}−E_{v}+c₁mB₀,
μ_{N}(v)≥μ_{M}(v)+G_{a}+F_{o}−E_{v}−L_{5}(v).
```

这两条分别控制商中的最大斜率和平均斜率。它们在这一步承担的是输入，来自哪里需要继续追读上游。

## 第 3 节 · 用平均斜率和最大斜率约束平移

设 `s=⟨μ_{N}(v)−h_{v}⟩`、`r=max_{v}[μ_{N}^{max}(v)−h_{v}]−s`。后者量化最大项比平均值能高出多少。由 `μ_{N}≤μ_{N}^{max}` 和权重正性，有 `r≥0`。

**损失（`LossBounds`）。** 写 `P_{0}=c_{loss}n_{T}mbx^{e_{loss}ε}`，要求 `ASK−G_{a}≤P_{0}` 且 `I_{O}≤P_{0}`。

**高度及变动参数（`HHBound`、`FParams`）。** 对每个 `u`，记相应参数为 `H_{*},δ_{u},η_{u},e_{u}`，要求

```text
s−μ^{min}_{CC}≤H_{*}, 0<H_{*}≤x^{c_{HH}}b,
0≤δ_{u}≤δ̄， 0≤η_{u}≤η̄， 0≤e_{u}≤ē.
```

**最后的斜率不等式（`SlopeIneq`）。** 当 `0≤δ_{u}<1`、`η_{u}≥0`、`0≤e_{u}≤1/4`、`s−μ^{min}_{CC}≤H_{*}` 且 `H_{*}>0` 时，要求成立

```text
s−log|W(u)|−[4r log(1+H_{*}/r)+(η_{u}+4√e_{u})H_{*}]/(1−δ_{u})≤μ_{CC}. （2）
```

`r=0` 时约定 `r log(1+H_{*}/r)=0`。这里的前提全部由上一条及基本符号条件提供。第 2、3 节列出的十一项恰好是 `LChain.SizeData₂`。

### 证明 先给平均斜率一个下界

把商格平均斜率的下界中的 `F_{o}−h_{v}` 用整除性给出的下界代替，再用 `S_{a}≥0` 与 `log T_{v}≥Λ_{5}`，同时代入 `E_{v}≤m(S_{a}ℓ_g+c_{E}B₀)` 及 `μ_{M}(v)≥−S_{0}(1+q)`。对所得不等式取正权平均，得到

```text
s ≥ G_{a} + μ_{CC} − K_{5} − ⟨L_{5}⟩,
K_{5}=S_{0}(1+q)+m(S_{a}ℓ_g+c_{E}B₀)+D_{0}−S_{a}Λ_{5}+D_{1}.
```

把 `Λ_{5}` 展开，`mS_{a}ℓ_g` 与其中的对数尺度项相抵；`mS_{a} log(π/v₀)` 也按定义抵消。剩下的是 `Main(u)` 和误差

```text
K_{5}=Main(u)+K_{0}, K_{0}=S_{a}J_{0}+D_{1}+m c_{E} B₀+S_{0}(1+q). （3）
```

这就是计数主项在斜率论证中出现的位置。

## 第 4 节 · 把斜率输入变成误差上界

对 `v,v′∈W(u)`，由指数比较得 `|E_{v}−E_{v′}|≤2m c_{E} B₀`。对高度比较展开括号，使用计数尺度的 `log T` 变动界。合起来得到

```text
(-E_{v}-h_{v})-(-E_{v′}-h_{v′}) ≤ V_{0},
V_{0}=2m c_{E}B₀+c_{H}(n_{T}a_{E} L_{a}+mB₀)+S_{a} c_{count}log k.
```

对第一个下标用商格最大斜率的上界，对第二个下标用商格平均斜率的下界，再作差。共同项 `G_{a}+F_{o}` 被消去，底格斜率相差至多 `S_{0}(2+q)`，指数与高度差至多 `V_{0}`。因此

```text
[μ_{N}^{max}(v)−h_{v}]−[μ_{N}(v′)−h_{v′}] ≤ K_{3}+L_{5}(v′),
K_{3}=S_{0}(2+q)+V_{0}+c₁mB₀.
```

对 `v′` 取正权平均，再对 `v` 取最大值得 `r≤K_{3}+⟨L_{5}⟩`。又由 `I_{O}≤P_{0}`、`log T_{v}≤c_{count}mL`，有

```text
⟨L_{5}⟩≤M_{5}:=c₁P_{0}+c₁n_{T}m(a_{E}/k+b′)c_{count}mL+c₁X″+1.
```

接下来控制（2）的对数项。一般地，若 `0≤r≤U_{*}`、`0<H_{*}≤Xb`、`X,b>0`，则

```text
r log(1+H_{*}/r) ≤ log(1+X)(U_{*}+b).
```

`r=0` 时直接成立。否则对 `(1+H_{*}/r)/(1+X)` 用 `log v≤v−1`，乘以 `r` 后得到上界 `r log(1+X)+(H_{*}−rX)/(1+X)`。再用 `H_{*}≤Xb` 和 `X/(1+X)≤log(1+X)`；后一不等式同样来自对 `1/(1+X)` 使用 `log v≤v−1`。这就是源码 `phi_bound`。

代入 `U_{*}=K_{3}+M_{5}`、`X=x^{c_{HH}}`。同时以 `δ̄,η̄,ē` 取代对应的参数上界。将（3）给出的 `s` 的下界代入（2），再用 `ASK≤G_{a}+P_{0}`，得到

```text
ASK−Main ≤ K_{0}+log|W(u)|+P_{0}+M_{5}
+ (1−δ̄)^{−1}[4·log(1+x^{c_{HH}})(K_{3}+M_{5}+b)+(η̄+4√ē)x^{c_{HH}}b]. （4）
```

这是 `each_unit_bound_statement` 的逐个平移版本，右端即源码的 `ErrX5at`。

## 第 5 节 · 把误差写成统一的一种大小

`ErrWindows` 要求以下条件。记 `y=x^{ε}`，`y_{D}=x^{e_{div}ε}`，`y_{L}=x^{e_{loss}ε}`。

- `x≥1`、`0<ε≤1`、`b≥1`、`a_{E}≥xb`、`n_{T}≥1`、`m≤x^{1/2+ε/2}`、`xm≤k`。
- `e_{K}≥0`，`1≤k≤x^{e_{K}}`，且 `k≤a_{E}`。`0≤L,L_{a}≤2y`、`b′≥0`、`kb′≤a_{E}`、`0≤X″≤a_{E}`。
- 对每个 `t` 有 `0≤a_{t}≤2a_{E}`。`B₀,N_{c}≥0`。对每个 `u` 有 `log|W(u)|≤(k−3)log 2`。
- `δ̄≤1/2`、`η̄,ē≥0`，且 `E_{*}= (η̄+4√ē)x^{c_{HH}}b ≤ K y n_{T}a_{E}`。
- 七个前置系数 `c_{div},c_{E},c_{H},c_{count},c_{slope},c₁,c_{loss}` 都位于 `[0,K]`。`e_{div},e_{loss},c_{HH}≥0`。

`LargeX` 再要求 `log x≤y` 与 `200(1+K)²(1+c_{HH})(1+e_{K})≤y`。最后，`BNBoundsU` 要求

```text
B₀≤2nmb y, N_{c} ≤ n₂kb y/(n²x^{−ε}).
```

由这些条件，`m≤x`，故 `mb≤a_{E}`；而 `xm≤k` 给出 `q≤1`。还得到 `a_{E}≥1`、`b′≤a_{E}/k`、`S_{a}≤2n_{T}a_{E}`、`log|W(u)|≤k≤a_{E}`。

记 `h=1+c_{HH}`、`g=1+e_{K}`，则 `log(1+x^{c_{HH}})≤hy`、`log k≤gy`。前一式用 `1+x^{c_{HH}}≤2x^{c_{HH}}`，后一式用 `k≤x^{e_{K}}`。并且 `0≤(1−δ̄)^{−1}≤2`。令

```text
E_{0}=n_{T}a_{E}(1+m²/k)+m(B₀+N_{c}), P=y_{D} y_{L} y E_{0}.
```

其中 `E_{0}` 是 `ErrText`，而 `E_{0}≥1`、`y_{D},y_{L},y≥1`。下一页逐项用 `P` 控制（4）。

## 第 6 节 · 为什么总共多出 3ε？

`P` 同时大于或等于 `yE_{0}, y_{D} E_{0}, y_{L} E_{0}, E_{0}`。以下分别用第 5 节的条件来估计。

- `S_{a} J_{0}≤4KP`，因为 `S_{a}≤2n_{T}a_{E}`、`L_{a}≤2y`。`D_{1}≤3KP`，其中整除性误差的两项分别至多 `2KP` 和 `KP`。
- `m c_{E} B₀≤KP`、`S_{0}(1+q)≤4KP`，所以（3）中的 `K₀≤12KP`。其次 `P_{0}≤KP`，因为 `mb≤a_{E}`。
- 在 `M_{5}` 中，`c₁P_{0}≤K²P`。使用 `n_{T} m²(a_{E}/k+b′)≤2n_{T}a_{E} m²/k≤2E_{0}` 和 `L≤2y`，它的第二项至多为 `4K²P`。再用 `X″≤a_{E}≤E_{0}` 和 `P≥1`，得到 `M_{5}≤(5K²+K+1)P`。
- 在 `K_{3}` 中，`S_{0}(2+q)≤6KP`；`V_{0}` 的三项依次至多为 `2KP,3KP,2KgP`，第三项用 `log k≤gy`。还有 `c₁mB₀≤KP`。因此 `K_{3}+M_{5}+b≤UP`，其中 `U=5K²+13K+2Kg+2`，最后的 `b≤P` 来自 `b≤a_{E}`。

所以（4）的前四项不超过 `(5K²+14K+2)P`。括号里的高度项用 `log(1+x^{c_{HH}})≤hy`，其余量 `E_{*}≤Ky n_{T}a_{E}≤KP`，再乘以至多 2 的倒数因子。总上界为

```text
[(5K²+16K+2)+8hU]·yP ≤ 200(1+K)² h g · yP ≤ y²P.
```

第一个不等式由 `h,g≥1, K≥0`。具体地，`U≤(5K²+15K+2)g`，于是方括号至多 `(45K²+136K+18) h g`。第二个不等式就是 `LargeX`。故（4）至多为 `y²P = x^{(e_{div}+e_{loss}+3)ε}E_{0}`。其中三份 `x^{ε}` 分别用于统一基本尺度与损失、控制对数、吸收常数。

最后由 `BNBoundsU` 得 `E_{0}≤B_{E}`，再用（1），即得对 `gap(tr(u))` 的所需上界，证毕。

## 第 7 节 · 前提与结论在哪一层？

这条链的输出是对每个给定平移的计数差上界。回到 `core_gm`，它用覆盖条件为每个 `h∈H₀` 找一个 `u` 使 `tr(u)=h`；再从 `e_{div}≤e_{D}`、`e_{loss}≤e_{L}` 得到供平移平均使用的 `C=e_{D}+e_{L}+3`。对给定的正 `ε` 和常数，`log x=o(x^ε)`、`x^ε→∞` 保证 `LargeX` 可由取足够大的阈值得到。[平移平均的证明](%E5%B9%B3%E7%A7%BB%E5%B9%B3%E5%9D%87%E5%A6%82%E4%BD%95%E7%BB%99%E5%87%BA%E7%B4%A0%E6%95%B0%E5%92%8C%E7%9A%84%E9%80%90%E7%82%B9%E4%BC%B0%E8%AE%A1.md)

全套输入中，差值估计的关键是第 2 节的整除性、商格斜率以及第 3 节的斜率不等式。它们共同把 `G_{a}` 放进一个含 `Main` 的区间里。本篇逐条写明它们的内容和用法。主线还须解释怎样为窗口上的每个点构造同时满足这些关系的数据。[斜率比较所需的矩阵迹界](%E6%A0%BC%E7%9A%84%E6%96%9C%E7%8E%87%E4%BC%B0%E8%AE%A1%E6%80%8E%E6%A0%B7%E7%94%A8%E5%88%B0%E7%9F%A9%E9%98%B5%E8%BF%B9.md) · [局部格与全局格的斜率比较](%E5%B1%80%E9%83%A8%E6%A0%BC%E7%9A%84%E6%96%9C%E7%8E%87%E6%80%8E%E6%A0%B7%E9%99%90%E5%88%B6%E5%85%A8%E5%B1%80%E6%96%9C%E7%8E%87.md) · [商格斜率的局部长度推导](%E5%B1%80%E9%83%A8%E9%95%BF%E5%BA%A6%E5%A6%82%E4%BD%95%E7%BB%99%E5%87%BA%E5%95%86%E6%A0%BC%E7%9A%84%E4%B8%A4%E6%9D%A1%E6%96%9C%E7%8E%87%E7%95%8C.md) · [上同调与整除损失的联系](%E4%B8%8A%E5%90%8C%E8%B0%83%E9%95%BF%E5%BA%A6%E6%80%8E%E6%A0%B7%E6%8E%A7%E5%88%B6%E5%B1%80%E9%83%A8%E6%95%B4%E9%99%A4%E6%8D%9F%E5%A4%B1.md)
