# 从窗口估计到黎曼猜想

[阅读入口](from-windows-to-rh.md)

## 第 1 节 · 黎曼猜想 · 条件定理的中文证明

假设 ζ 函数有一个零点，实部比 ½ 大一点。要排除它，作者需要把一个加权素数和的增长指数压到这个实部以下。值得注意的是，这个上界只需要在某些越来越远的完整区间上成立。下面说明所需的算术条件，以及它怎样推出黎曼猜想。

### 所估计的是哪个量？

记 `Λ(n)` 为冯·曼戈尔特函数：当 `n = p^{k}` 是素数的正整数次幂时取 `log p`，其余取零。对实数 `x ≥ 1` 和狄利克雷特征 `χ`，记

```text
S_{χ}(x)=∑_{1≤n≤x}Λ(n)χ(n)((x)/(n)−1).
```

模 1 的平凡特征记为 `𝟙`。它对应 ζ 函数。减去主项后得到 `G_{𝟙}(x) = S_{𝟙}(x) − x log x + (1 + γ)x`，其中 `γ` 是欧拉常数。对非平凡本原特征，令 `G_{χ}(x) = S_{χ}(x) + x L′(1,χ)/L(1,χ)`。原证明固定一个含 `𝟙` 的有限特征族 `𝓛`，使用该层规定的正权重 `w_{χ}`（`w_{𝟙} = 1`），估计实数

```text
G_{𝓛}(x)=∑_{χ∈𝓛}w_{χ} Re G_{χ}(x).
```

### 定理的算术前提

固定上述层 `𝓛`、实数 `λ > 1`、两个指数常数 `e_{D}, e_{L}` 及 `ε₁ > 0`。假设对每个 `0 < ε < ε₁`，都能选到一族算术数据 `F` 和它的窗口集合 `W`，满足以下三条。

**（一）窗口可以任意远。** 对每个实数 `T`，都存在 `Y ≥ T` 使整个闭区间 `[Y, Y^{λ}] ⊆ W`。不同窗口之间允许留有空隙。

**（二）全体候选数据满足一组共同条件。** 存在 `C, x_{E}`，对所有 `x ≥ x_{E}`，族 `F` 在 `x` 处的每个候选都与层 `𝓛` 相容，并满足项目规定的分布及特征估计。其中包括相应特征在 1 处的对数导数绝对值至多为 `C log x`。这组条件在原文记作 `EAtH`。

**（三）窗口上每个大点至少有一个可用的候选。** 存在 `K, c_{HH}, e_{K}, x₀`，使每个 `x ∈ W` 且 `x ≥ x₀` 都有一个候选满足 `CoreAtH`。这是原文的一组算术恒等式、覆盖条件、尺度及余项估计，所用损失指数受 `e_{D}, e_{L}` 控制。候选可随 `x` 改变。

**条件定理。** 若存在满足以上前提的层与常数，则 ζ 的每个非平凡零点的实部都等于 ½。此处允许 `F, W` 以及（二）（三）中的常数随 `ε` 改变。证明窗口和数据本身存在，是这一段留给上游的算术问题。

## 第 2 节 · 怎样排除一个假想的零点？

### 第一步 让两组算术条件落在同一个候选上

固定 `ε` 并按前提取 `F, W`。引用原文的逐点估计引理 `core_gm`：在这些常数下存在阈值 `x₁`，只要 `x ≥ x₁`，且同一份数据同时满足 `EAtH` 与 `CoreAtH`，就有

```text
G_{𝓛}(x) ≤ x^{1/2 + (e_{D} + e_{L} + 7)ε} .
```

取 `X = max{x₁, x₀, x_{E}}`。对任意 `x ∈ W` 且 `x ≥ X`，先由（三）挑出一个满足核心估计的候选，再由（二）知这个候选也满足第一组条件。因此上式对窗口上每一个这样的 `x` 都成立，同一个 `X` 对这些点全部有效。

**指数中的 7 从哪里来？** 在所选数据上写 `a = ½ + (e_{D} + e_{L} + 6)ε`，以 `o` 记层附带的非负整数。原文用已证的算术估计将 `G_{𝓛}(x)` 控制为 `x^{a} + 4o x^{1/2 + ε}`。数据条件给出 `e_{D} + e_{L} ≥ 0`，故当 `x ≥ 1` 时，后者至多为 `(1 + 4o)x^{a}`。固定 `ε > 0` 后，充分大的 `x` 满足 `1 + 4o ≤ x^{ε}`。于是指数从 `a` 变为 `a + ε`，这正是上式。

### 第二步 在 ½ 与零点之间选一个指数

若有一个 ζ 的零点 `s` 满足 `β = Re s > ½`，记 `B = e_{D} + e_{L} + 7`。取

```text
d = ½ min{β − ½, ½}, θ = ½ + d, ε = min{ε₁/2, d/(|B| + 1)}.
```

于是 `½ < θ < β` 且 `θ < 1`。又有 `0 < ε < ε₁` 且 `Bε ≤ d`。这里用到了量词的次序：两个损失指数已经固定，所以无论零点离临界线多近，都可以把 `Bε` 压到这段间隙之内。

对这个 `ε` 应用第一步。给定任意起点 `T`，由（一）选 `Y ≥ max{T, X, 1}`，使 `[Y,Y^{λ}] ⊆ W`。对区间内的每个实数 `x`，都有

```text
G_{𝓛}(x) ≤ x^{1/2 + Bε} ≤ x^{θ} .
```

下一页的解析引理于是给出，族内每个 `L` 函数在 `Re z > θ` 都没有零点。模 1 的平凡特征属于该族，且 `L(z,𝟙) = ζ(z)`。由于 `β > θ`，这与 `ζ(s) = 0` 矛盾。故临界线右侧没有 ζ 零点。

### 第三步 用函数方程排除左侧

若非平凡零点 `s` 满足 `Re s < ½`，则 `Re(1 − s) > ½`。ζ 的函数方程给出

```text
ζ(s) = 2^{s}π^{s−1} Γ(1 − s) sin(πs/2) ζ(1 − s).
```

此处 `Γ(1 − s)` 有限且非零。正弦因子为零只可能在偶整数；在这个半平面中，负偶数已由“非平凡”排除，而 `ζ(0) = −½`。因此 `ζ(s) = 0` 强迫 `ζ(1 − s) = 0`，与第二步矛盾。剩下的可能只有 `Re s = ½`。证毕。

## 第 3 节 · 为什么只控制一些区间就够？

**窗口零点判据。** 对第 1 节的特征族及其加权和，固定 `λ > 1` 和 `0 < θ < 1`。若对每个 `T` 都能找到 `Y ≥ T`，使所有 `Y ≤ y ≤ Y^{λ}` 满足 `G_{𝓛}(y) ≤ y^{θ}`，则族中每个 `L(s,χ)` 在 `Re s > θ` 无零点（平凡特征在 1 处有极点）。

这是第二步引用的实质性解析结果。下面给出原证明把区间上界传给零点定理的计算，并指出其中引用的深层引理。

### 把一个区间上的估计变成积分估计

任取 `η > 0`。在一个足够远的窗口上，取非负上界 `R(y) = y^{θ}`。它的加权积分可精确算出：

```text
∫_{Y}^{Y^{λ}}R(y)y^{−θ−1} dy=∫_{Y}^{Y^{λ}}(dy)/(y)=(λ−1)logY≤Y^{η}.
```

最后一个不等式对一切充分大的 `Y` 成立，因此“窗口可以任意远”恰好让我们跨过它的阈值。取 `u = log y`、`U = log Y`，窗口就变成 `[U, λU]`。其长度是 `(λ − 1)U`。只知道某个孤立点上的函数值，无法给出这个区间的积分控制。

### 零点怎样进入这个论证？

令 `g(u) = G_{𝓛}(e^{u})`。项目先在 `Re z > 2` 写出拉普拉斯变换

```text
Φ(z)=∫_{0}^{∞}g(u)e^{−zu} du.
```

原文的极点引理证明，`Φ` 在右半平面有亚纯延拓；若族中某个 `L` 函数在 `0 < Re ρ < 1` 有零点，则 `ρ` 是这个延拓的极点，主部为 `c/(z − ρ)`，且 `c ≠ 0`。因此，对这个特定加权和的控制能够约束每个成员的零点。

接下来引用原文的 **Landau 窗口引理**：对具有该极点结构的变换，若任意远的对数窗口都可按上述方式选取，使加权积分对每个 `η > 0` 至多为 `e^{ηU}`，则每个所述极点都满足 `Re ρ ≤ θ`。用刚算出的积分验证其前提，就排除了 `θ < Re ρ < 1` 的零点。`Re ρ ≥ 1` 的情形由原文另外调用的狄利克雷 `L` 函数非零定理处理。这就得到本节的判据。极点引理与 Landau 窗口引理的内部证明在此作为已证引理引用。
