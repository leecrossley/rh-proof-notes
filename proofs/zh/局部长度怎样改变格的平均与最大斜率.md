# 局部长度怎样改变格的平均与最大斜率？

## 第 1 节 · 命题 · 格的指数与两种斜率

商格斜率的证明把两种不同的信息加到一起。平均斜率由一个有限商的大小精确决定，最大斜率只需知道子格在各素理想处的包含关系。这一篇从理想范数和余体积展开两条推理。[后续的大小估计](%E5%B1%80%E9%83%A8%E9%95%BF%E5%BA%A6%E5%A6%82%E4%BD%95%E7%BB%99%E5%87%BA%E5%95%86%E6%A0%BC%E7%9A%84%E4%B8%A4%E6%9D%A1%E6%96%9C%E7%8E%87%E7%95%8C.md)

取全虚数域 `K`、整数环 `R=𝒪_{K}` 和 `n=[K:ℚ]`。在有限维 `K` 向量空间 `V` 中选定一组基，并给每个无穷处选定任意可逆复坐标变换，用所有无穷处的实部、虚部坐标赋予欧氏度量。对一个有限生成、正秩的 `R` 子模 `A`，记 `d_{A}=dim_{K}(KA)`，其实现的欧氏格在实线性包中的余体积为 `covol A`。记

```text
μ(A)=−2 log(covol A)/(nd_{A}) − log 2 + log|disc K|/n,
μ_{max}(A)=sup{μ(B): 0≠B⊆A 是 R 子模}.
```

这是源码中 `muDef`、`muMaxDef` 的归一化。在固定度量下，记 `ℓ_{𝔭}(M/N)` 为 `R` 模 `M/N` 在非零素理想 `𝔭` 处局部化后，作为局部环 `R_{𝔭}` 模的长度。记 `λ_{𝔭}=log(N𝔭)/n`，其中 `N𝔭=|R/𝔭|`。

**平均斜率公式。** 对所有有限生成的 `M⊆V` 及子模 `0≠N⊆M`，若 `d=d_{M}=d_{N}`，则所有局部长度有限且仅有限多个非零。对任意包含其支集的有限素理想集 `S`，

```text
μ(N)=μ(M)−(2/d)∑_{𝔭∈S}λ_{𝔭}ℓ_{𝔭}(M/N). (1)
```

**最大斜率上界。** 给任意非零有限生成 `M,N⊆V`、非零分式理想 `I`、有限素理想集 `S` 和非负整数 `k_{𝔭}`（在 `S` 外取零）。若每个非零素理想都有 `N_{𝔭}⊆𝔭^{k_{𝔭}}M_{𝔭}`，则

```text
μ_{max}(IN)≤μ_{max}(M)−(2/n)log N(I)−2∑_{𝔭∈S}λ_{𝔭}k_{𝔭}. (2)
```

## 第 2 节 · 为什么全局指数是素理想范数的乘积？

先证明（1）。由于 `N⊆M` 且二者的 `K` 秩相同，有 `KN=KM`。对 `M` 的每个生成元，在它由 `N` 中元素表示的 `K` 线性组合里清去分母。取这些非零分母的乘积 `a∈R`，便有 `aM⊆N`。因此 `M/N` 是有限环 `R/aR` 上的有限生成模，作为集合有限。

对任意有限 `R` 模 `Q`，取一条分解列。每个简单因子都是 `R/𝔭`，其中 `𝔭` 是极大理想。这是因为简单模由任一非零元生成，其湮灭理想必为极大理想。每一步的短正合列使基数相乘，所以 `|Q|` 是所有因子基数的乘积。

现在在一个非零素理想 `𝔮` 处局部化。局部化是正合的。如果 `𝔭≠𝔮`，可以从 `𝔭∖𝔮` 选一元素，它原来湮灭 `R/𝔭`，局部化后变成单位，于是该因子变为零。如果 `𝔭=𝔮`，该因子就是局部环的剩余域，长度为 1。故分解列里标记为 `𝔮` 的因子个数正是 `ℓ_{𝔮}(Q)`。这同时证明了局部长度有限且有有限支集，并给出

```text
[M:N]=|M/N|=∏_{𝔭∈S}(N𝔭)^{ℓ_{𝔭}(M/N)}. (3)
```

格 `N` 与 `M` 的实线性包相同。一个 `N` 的基本域可以由 `[M:N]` 个平移后的 `M` 基本域组成，所以 `covol N=[M:N]·covol M`。两格的 `ℤ` 秩同为 `nd`，归一化的常数也相同。于是斜率差为 `−2 log[M:N]/(nd)`，将（3）代入即得（1）。

## 第 3 节 · 为什么乘理想只平移斜率？

先对任一非零有限生成格 `A` 和任一非零整理想 `J` 求 `[A:JA]`。在 `𝔭` 处，`A_{𝔭}` 是离散赋值环上的有限生成无挠模，因而是秩为 `d_{A}` 的自由模。若 `J` 在该处由统一化元的 `v_{𝔭}(J)` 次幂生成，商的长度就是 `d_{A}v_{𝔭}(J)`。由（3），`[A:JA]=N(J)^{d_{A}}`。

对于分式理想 `J`，可选非零 `a∈R` 使 `aJ` 为整理想。比较 `A` 与 `aJA` 的余体积，以及 `JA` 与 `aJA` 的余体积。由范数的乘法性消去 `N(aR)^{d_{A}}` 得 `covol(JA)=N(J)^{d_{A}}·covol A`。因此

```text
μ(JA)=μ(A)−(2/n)log N(J).
```

给定 `JA` 的任一非零子格 `B`，有 `J^{−1}B⊆A`，且 `J(J^{−1}B)=B`。所以 `μ(B)≤μ_{max}(A)−(2/n)log N(J)`。对所有 `B` 取上确界，得到乘分式理想后的最大斜率界。

回到（2）。置 `J=∏_{𝔭∈S}𝔭^{k_{𝔭}}`。不同的素理想在 `𝔭` 处局部化后成为单位理想，所以假设正是 `N_{𝔭}⊆(JM)_{𝔭}` 对所有 `𝔭` 成立。这蕴含 `N⊆JM`。否则取 `x∈N∖JM`，在商中它的湮灭理想是一个真理想，取含它的极大理想 `𝔭`。这时没有 `𝔭` 外的元素能把 `x` 乘入 `JM`，与局部包含矛盾。

因此 `IN⊆(IJ)M`。最大斜率对于包含关系单调，对 `IJ` 用刚证出的平移界，并用 `log N(J)=∑_{𝔭∈S}k_{𝔭}log N𝔭`，得到（2）。

## 第 4 节 · 这两条公式怎样生成上游数据？

实际代码先有一个参考格 `M`，以及与它可公度、且包含于它的格 `N`。记对应的素理想为 `𝔭_{w}`。给定分歧指数 `e_{w}>0` 和局部指数 `g_{w}`，项目对 `N` 乘以分式理想 `I=∏_{w}𝔭_{w}^{−⌊e_{w}g_{w}⌋}`，得到实际参加比较的格。把记录的局部长度 `L_{w}` 换回局部环长度时，等式是 `ℓ_{𝔭_{w}}(M/N)=e_{w}L_{w}`。这是应用所给的记录兼容性。

写 `λ_{w}=e_{w}λ_{𝔭_{w}}`、`g′_{w}=⌊e_{w}g_{w}⌋/e_{w}`。乘理想的平移公式和（1）合起来给出

```text
μ(IN)=μ(M)+2∑_{w}λ_{w}g′_{w}−(2/d)∑_{w}λ_{w}L_{w}.
```

对最大斜率，局部包含所给的指数为 `k_{w}=e_{w}τ_{w}`，其中 `τ_{w}` 是非负整数。因此（2）给出

```text
μ_{max}(IN)≤μ_{max}(M)+2∑_{w}λ_{w}(g′_{w}−τ_{w}).
```

这就是上一篇把中间格斜率与目标格斜率相联系的两条局部公式。它们还要用各处的长度上界和对舍入损失的估计，才会得到实际使用的商格界。[由公式推出商格界](%E5%B1%80%E9%83%A8%E9%95%BF%E5%BA%A6%E5%A6%82%E4%BD%95%E7%BB%99%E5%87%BA%E5%95%86%E6%A0%BC%E7%9A%84%E4%B8%A4%E6%9D%A1%E6%96%9C%E7%8E%87%E7%95%8C.md)
