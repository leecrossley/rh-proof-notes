# 零点矩形怎样控制截断素数和的尾项

## 第 1 节 · 命题

令 `Λ` 为 von Mangoldt 函数，`χ` 为模正整数 `N` 的狄利克雷特征。对 `y>0` 定义带斜坡权重的素数幂和及其误差

```text
A_{χ}(y)=∑_{1≤n≤y} Λ(n)χ(n)(y/n−1)， g_{χ}(y)=A_{χ}(y)+y(L′/L)(1,χ)。
```

在正整数 `n` 上记 `J_{q}(n)=(n/q)` 为工程使用的 Jacobi 符号，一个奇素数 `q` 时就是 Legendre 符号。对任意序列 `κ:ℕ→ℂ` 定义另一种权重的有限和

```text
S(Z,y,q,κ)=∑_{1≤n≤Z} Λ(n)κ(n)J_{q}(n) min(1,y/n)。
```

**定理。** 存在绝对常数 `C>0`。对每组实数 `0<ε≤1/4`、`τ>0`、`K≥1`，存在实阈值 `Y₀`，使得以下结论对每个 `Y≥Y₀`、每个实数 `Q`、每个正整数 `N`、每个模 `N` 的特征 `χ`、每个自然数 `q` 和序列 `κ` 成立。设 `X=Y^{K}`、`Z=X^{400}`，并假定

- `Y^{ε/6}≤log Q≤Y^{ε/4}`，`χ` 非主，`N≤Q`，且 `L(s,χ)≠0` 对所有 `Re s>1−1/400`、`|Im s|≤Q` 成立。
- 每个自然数 `n` 有 `χ(n)=κ(n)J_{q}(n)`。
- 每个 `y∈[Y,X]` 有 `|S(Z,y,q,κ)|≤½y^{1/2+τ}`。

那么 `|(L′/L)(1,χ)|≤C log Y`，且每个 `y∈[Y,X]` 有 `|g_{χ}(y)|≤y^{1/2+τ}`。

这是 `QH.box_of_S` 的实质结论。筛选步骤直接控制的是 `S`，而逐点估计中使用的是 `g_{χ}`。本篇证明如何由前者得到后者。[辅助素数筛选](%E6%80%8E%E6%A0%B7%E6%8C%91%E5%87%BA%E5%90%8C%E6%97%B6%E6%BB%A1%E8%B6%B3%E6%89%AD%E6%9B%B2%E4%BC%B0%E8%AE%A1%E7%9A%84%E7%B4%A0%E6%95%B0%E5%AF%B9.md)

## 第 2 节 · 把截断对数导数写成一个差分

令 `D_{χ}=−(L′/L)(1,χ)`、`P(z)=∑_{1≤n≤z}Λ(n)χ(n)/n`，记 `R(z)=D_{χ}−P(z)`。工程的 `tailL` 就是 `R`。我们用一个差分，将估计 `R(z)` 化成两种对 `A_{χ}` 的估计。

**解析输入（`tail_contour`）。** 对任意 `0<δ≤1/800`，存在 `B≥0`，使得以下不等式对任意实数 `Q≥2`、正整数 `N≤Q`、模 `N` 的非主特征 `χ`、`z≥1` 和 `0<η≤1` 成立，只要 `L(s,χ)` 在 `Re s>1−1/400`、`|Im s|≤Q` 无零点。写 `h=zη`，有

```text
|A_{χ}(z+h)−A_{χ}(z)−hD_{χ}| ≤ B log Q [log Q·η z^{1−1/400+δ} + z²/Q]。
```

零点条件的用途是允许把 Perron 积分在高度 `Q/2` 的截断矩形中向左移动，至 `Re s=1−1/400+δ`。工程在这条竖线上估计两次积分之差，核函数的分子含 `(1+η)^{s}−1`，从而得到 `η` 因子。两段横边以及起始直线上截去的两段尾部由 `z²/Q` 型的界控制。上面的完整不等式是下面所用的输入。[TailContour.lean](https://github.com/tamnd/riemann-lean/blob/9110120cdc195ee8d2fb08d2adac8b1747912d8f/lean/src/Formalism/GL3MeanSquares/GenusMeanAsymptotics/JacobiCharacterSums/TailContour.lean) · [TailKernel.lean](https://github.com/tamnd/riemann-lean/blob/9110120cdc195ee8d2fb08d2adac8b1747912d8f/lean/src/Formalism/GL3MeanSquares/GenusMeanAsymptotics/JacobiCharacterSums/TailKernel.lean)

另一方面，直接把 `A_{χ}(z+h)−A_{χ}(z)` 的和按 `n≤z` 与 `z<n≤z+h` 拆开。前者的权重之差是 `h/n`，后者只来自第一项，权重为 `(z+h)/n−1≤h/z`。因为 `|χ(n)|≤1`、`Λ(n)≤log(z+h)`，而新区间至多含 `h+1` 个整数，所以

```text
|A_{χ}(z+h)−A_{χ}(z)−hP(z)| ≤ h(h+1)log(z+h)/z。
```

两个差分表达式相减便得到 `hR(z)`。把各自的界相加，再除以正数 `h`，就得到所需的尾项估计。[TailDiff.lean](https://github.com/tamnd/riemann-lean/blob/9110120cdc195ee8d2fb08d2adac8b1747912d8f/lean/src/Formalism/GL3MeanSquares/GenusMeanAsymptotics/JacobiCharacterSums/TailDiff.lean)

## 第 3 节 · 为什么尾项最多是一个很小的幂？

先允许 `0<ε≤1` 和 `K≥1`，令 `x=Y^{K}`、`z=x^{400}`、`η=x^{−2}`、`δ=ε/(1600K)`。对 `Y≥3`，已有 `0<η≤1` 和 `0<δ≤1/800`。对数下界与 `N≤Q` 给出 `Q≥exp(Y^{ε/6})≥2`，故可以使用前节的解析输入。将前节所得的界乘以 `x`，代入 `h=zη=x^{398}` 后得到

```text
x|R(z)| ≤ B(log Q)²Y^{ε/4} + B(log Q)x^{403}/Q + (x^{−1}+x^{−399})log(z+h)。
```

第一项中，`x z^{−1/400+δ}=x^{400δ}=Y^{ε/4}`。用 `log Q≤Y^{ε/4}`，第一项至多为 `B Y^{3ε/4}`，所以当 `Y` 足够大时至多为 `Y^{ε}/3`。

第二项用下界 `Q≥exp(Y^{ε/6})`。由于 `log Q≤Y^{ε/4}≤x`，它至多为 `B Y^{404K}exp(−Y^{ε/6})`。令 `t=Y^{ε/6}`，这是常数乘以 `t` 的固定幂再乘 `e^{−t}`，故趋于 0。特别地，最终至多为 `1/3≤Y^{ε}/3`。

第三项中，`z+h≤2x^{400}≤x^{401}`，且 `x^{−399}≤x^{−1}`，故总共至多为 `802(log x)/x≤802`，最终也至多为 `Y^{ε}/3`。三者的取大阈值只用 `ε,K`，所以对该阈值之后的每个 `Y` 和允许的 `Q,N,χ` 都有

```text
x|R(x^{400})| ≤ Y^{ε}。
```

这就是 `tailK`。若只需要控制 `yR(x^{400})`，则在 `y≤x` 时可直接使用同一个上界。

## 第 4 节 · 有限和如何还原成所需的误差？

先取 `K=1` 用一次尾项估计，得到 `|R(Y^{400})|≤Y^{ε−1}≤1`。Chebyshev 上界 `∑_{n≤t}Λ(n)≤2t` 经部分求和给出绝对常数 `C₀≥0`，对 `z≥2` 有 `∑_{n≤z}Λ(n)/n≤C₀ log z`。具体地，上界是 `2+2 log z`，可并入常数。由于 `|χ(n)|≤1`，同一上界控制 `|P(z)|`，故

```text
|D_{χ}|≤|P(Y^{400})|+|R(Y^{400})|≤400C₀ log Y+1≤(400C₀+1)log Y
```

对 `Y≥3` 成立。这个常数与 `ε,τ,K` 都无关。[TailMertens.lean](https://github.com/tamnd/riemann-lean/blob/9110120cdc195ee8d2fb08d2adac8b1747912d8f/lean/src/Formalism/GL3MeanSquares/GenusMeanAsymptotics/JacobiCharacterSums/TailMertens.lean)

再取命题的 `K`、`Z=(Y^{K})^{400}`。固定 `y∈[Y,Y^{K}]`。对任意 `n≥1`，有 `(y/n−1)_{+}+min(1,y/n)=y/n`。由于 `Z≥y`，可将 `A_{χ}(y)` 补零写成截至 `Z` 的和。在等式的三项上分别乘 `Λ(n)χ(n)`，求和并用 `χ=κ J_{q}`，得到

```text
A_{χ}(y)+S(Z,y,q,κ)=yP(Z)， g_{χ}(y)=−S(Z,y,q,κ)−yR(Z)。
```

现在前一项按假设至多为 `½y^{1/2+τ}`，后一项由 `tailK` 至多为 `Y^{ε}`。若 `Y≥16`，则 `Y^{1/4}≥2`，从而 `Y^{ε}≤Y^{1/4}≤½Y^{1/2}≤½y^{1/2+τ}`。相加即得命题的窗口上界。取各步的阈值之最大值，常数与各项的量词遂都满足。
