# 平移平均如何给出逐点估计？

## 第 1 节 · 黎曼猜想 · 算术估计的有限群部分

在任意一个足够大的尺度 `x`，原证明先假定对每次平移都能控制某个计数与主项之差，再把这些不等式平均成一条加权素数和的上界。这是 `Deduction.ch_core` 的内容。本篇把它的条件和证明都展开。

### 对象

取有限交换群 `H`，令 `A=(ℤ/2ℤ)²×H`、`Φ={(0,j,h)∈A}`、`f=|Φ|=2|H|`。沿用前篇的局部数据 `(D,S)` 及其条件 `HostFactsS`，并记 `G_{ψ}(y)` 为其中对 `ψ∈Â` 定义的斜坡素数和误差，`ℓ:Â→ℂ` 是用来修正主项的任意函数。平凡特征记为 `1`。记前篇的 `ASK`、`MAIN`、`De` 为 `A_{t}(D,N,a,w)`、`M(a,w)`、`Δ(D,ℓ,a,t,w)`。本篇第 3 节用到前篇的等式；这些符号及全部局部条件可在其中的前两页查阅。[计数恒等式的定义与证明](%E5%89%A9%E4%BD%99%E7%B1%BB%E7%B4%A0%E6%95%B0%E5%92%8C%E4%B8%8E%E4%B8%BB%E9%A1%B9%E7%9A%84%E6%81%92%E7%AD%89%E5%BC%8F.md)

给定子群 `H₀≤H`。记 `Ψ` 为所有在 `{(0,0,h):h∈H₀}` 上平凡的特征。取一个保留特征集 `K_{p}⊆Ψ`。给定实数 `c`，设 `c_{ψ}=1` 若 `ψ(0,0,h)=1` 对所有 `h∈H` 都成立，其余取 `c_{ψ}=c`。我们要估计的量及未保留项为

```text
G_{m}(x)=∑_{ψ∈K_{p}} c_{ψ} Re G_{ψ}(x), Σ(x)=∑_{ψ∈Ψ∖K_{p}}|G_{ψ}(x)|.
```

取自然数 `N,m`，有限集 `T,T₂⊆H`，函数 `a:H→ℝ`，和权重函数族 `w_{u,j}:A→ℝ`（`u∈H,1≤j≤m`）。记 `n=|H|`、`n_{T}=|T|`、`n₂=|T₂|`。给定实数 `b,b′,k,a_{E},η,X′,τ`，定义

```text
gap(u)=∑_{t∈T}∑_{j=1}^{m}[A_{t}(D,N,a(t),w_{u,j})−Re M(a(t),w_{u,j})],
B_{E}=n_{T}a_{E}(1+m²/k)+m[2nmbx^{ε}+n₂kbx^{ε}/(n²x^{−ε})].
```

`gap(u)` 是同一平移下把各个计数与主项之差加起来。`B_{E}` 是上游算术估计允许的余项大小。

**定理。** 对每组固定的实数 `C,ε,C_{E},K₀,c,M₀`，其中 `C≥0, ε>0, |c|≤1`，存在实阈值 `x₁`。对每个实数 `x≥x₁`，上述对象只要满足第 2 节列出的条件，就有

```text
G_{m}(x) ≤ x^{1/2+(C+3)ε} + Σ(x).
```

## 第 2 节 · 哪些量要提前控制？

**一、计数与尺度。** 第 1 节的局部数据满足前篇的 `HostFactsS`。另有 `T₂⊆H₀`，`b>0, a_{E}≥0, k>0`，并且

```text
a_{E}≤2xb, n_{T}≥nx^{−ε/8}/2, n₂/n≥x^{−ε},
x^{1/2−ε}≤m≤x^{1/2+ε/2}, xm≤k≤n²x^{1/2−ε}.
```

**二、各项权重。** 有 `η≥0, X′>0, b′>0, b′X′≤xb, τ≥0`。对每个 `t∈T`，有 `|a(t)/b−x|≤1`。对任意 `u∈H₀`、`1≤j≤m`，把集合 `Φ` 中属于 `{(0,1,s+u):s∈T₂}` 的点称为厚点。要求每个 `ρ∈Φ` 都有 `w_{u,j}(ρ)>0`，并且当 `ρ` 为厚点时

```text
b ≤ w_{u,j}(ρ) ≤ b+η+1,
```

其余点满足 `w_{u,j}(ρ)≤2b′`。对每个 `t∈T`，所有这些权重还满足 `a(t)/w_{u,j}(ρ)≤N`。这是为了能应用计数恒等式的截断条件。

**三、小权重对应的输入。** 对所有 `ψ∈Â` 及所有实数 `y≥X′/3`，要求 `|G_{ψ}(y)|≤yτ`。同时要求

```text
2f(x+1)τ ≤ 1/x, 6f(x+1)(η+1) ≤ b/x.
```

**四、保留特征及分布。** `1∈K_{p}⊆Ψ`，且对所有 `ψ∈K_{p}`，有 `ψ(1,0,0)=1`。另外 `|Ψ|≤M₀`。记 `χ_{ψ}(t)=ψ(0,0,t)`。对每个 `ψ∈K_{p}` 且 `χ_{ψ}` 非平凡，要求

```text
|∑_{t∈T}χ_{ψ}(t) − c n_{T}| ≤ M₀ x^{−1+ε}n_{T}.
```

若 `ψ∈K_{p}∖{1}`，有 `|ℓ(ψ)|≤K₀`。若 `ψ∈Ψ∖K_{p}`，有 `|ℓ(ψ)|≤C_{E}log x`。

**五、上游给出的计数差上界。** 对每个 `u∈H₀`，都有

```text
gap(u) ≤ E, E=x^{Cε}B_{E}.
```

第二、三、四组条件分别来自 `SizesA`、`ThinScales` 与 `CostWindows`、`CharsA`。这里的 `τ` 是允许的小权重误差系数，与零点判据中的指数无关。第五组条件是这一段接受的算术估计，后面的平均步骤会把它传给 `G_{m}`。

## 第 3 节 · 保留厚点，把它们的权重换成 b

以下取 `x≥3`。设 `y_{t}=a(t)/b`，则 `x−1≤y_{t}≤x+1`，故 `a(t)>0`。计数恒等式允许把每一项 `A_{t}−Re M` 换成 `Re Δ`。它是对 `g∈Φ^{c}` 及 `ψ∈Â` 的求和，每项含 `w G_{ψ}(a(t)/w)`，其中 `w=w_{u,j}(P_{t}(g))`，`P_{t}(g)=g+(1,1,t)`。现在比较原和与只保留厚点、并把其权重统一取为 `b` 的和。

**权重变动引理。** 对任意有限交换群 `H`、任意局部数据 `D`（指定惯性子群与代表元）、任意 `ℓ:Â→ℂ`、任意 `ψ∈Â` 以及任意实数 `A_{*},w,w′>0`，有

```text
|wG_{ψ}(A_{*}/w)−w′G_{ψ}(A_{*}/w′)| ≤ 3 A_{*} |w−w′|/min(w,w′).
```

这是源码 `lipschitz_weight_all` 的完整结论。它来自斜坡函数 `w↦(A_{*}/n−w)_{+}` 的变动至多 `|w−w′|`，以及初等界 `∑_{1≤n≤Y}Λ(n)≤3Y`（`Y≥0`）。展开时只需加到 `n≤A_{*}/min(w,w′)`。对非平凡特征，修正项 `A_{*}ℓ(ψ)` 在作差时消去，且局部系数的模至多为 1。对平凡特征，若 `w≤w′`，斜坡和之差和主项之差 `A_{*}log(w′/w)` 都在 `[0,3 A_{*}(w′−w)/w]` 内，后者用 `log v≤v−1`。因此两差相减也满足所需的模界。[两条变动界的详证](%E6%96%9C%E5%9D%A1%E7%B4%A0%E6%95%B0%E5%92%8C%E4%B8%BA%E4%BD%95%E8%83%BD%E7%A7%BB%E5%8A%A8%E5%B0%BA%E5%BA%A6%E5%92%8C%E6%9D%83%E9%87%8D.md)

如果 `P_{t}(g)` 是厚点，条件二给出 `b≤w≤b+η+1`。应用权重变动引理，一项的变化至多为 `3(x+1)(η+1)`。如果是其余点，则 `w≤2b′`，所以

```text
a(t)/w ≥ (x−1)b/(2b′) ≥ xb/(3b′) ≥ X′/3.
```

由条件三，删去这一项的代价至多 `w·(a(t)/w)τ = a(t)τ ≤ (x+1)bτ`。两个上界都与 `g,ψ,u,j,t` 无关。共有 `f` 个 `g`、`2f` 个 `ψ`，各项还乘以模为 1 的 `ψ(−g)` 并统一除以 `f`。所以实部的误差至多

```text
2f[3(x+1)(η+1)+(x+1)bτ] ≤ 2b/x.
```

最后一个不等式恰好是条件三的两条数值约束。对每个 `t∈T` 和 `j` 都可以这样比较。

## 第 4 节 · 平移平均筛出哪些特征？

记 `e(h)=(1,0,h)`。因为 `P_{t}(g)=g+(1,1,t)`，一个厚点 `(0,1,s+u)` 恰好与 `g=e(s+u−t)` 配对。上节替换后得到的和不依赖 `j`，可写成

```text
T(u,t)= (b/f) ∑_{s∈T₂}∑_{ψ∈Â} ψ(−e(s+u−t)) G_{ψ}(y_{t}).
```

上节给出 `Re T(u,t)≤Re Δ(D,ℓ,a(t),t,w_{u,j})+2b/x`。先在 `t,j` 上求和，利用计数恒等式和条件五，得到对每个 `u∈H₀` 有

```text
m∑_{t∈T} Re T(u,t) ≤ E+2n_{T}mb/x.
```

现在对所有 `u∈H₀` 求和。由于第一坐标模 2，

```text
−e(s+u−t)=e(t)+(0,0,−s)+(0,0,−u).
```

对一个固定特征 `ψ`，`∑_{u∈H₀} ψ(0,0,−u)` 在 `ψ∈Ψ` 时等于 `|H₀|`，其余为零。后一结论来自非平凡特征在有限群上的和为零，可将求和按一个令特征值不为 1 的元素重新平移。又因 `s∈T₂⊆H₀`，对于留下的特征有 `ψ(0,0,−s)=1`。所以令 `δ₂=n₂/n`，就有

```text
|H₀|^{−1}∑_{u∈H₀}T(u,t) = (bδ₂/2)∑_{ψ∈Ψ}ψ(e(t))G_{ψ}(y_{t}).
```

这里的 `1/2` 来自 `f=2n`。把它代入平均后的首个不等式可得

```text
(mbδ₂/2)∑_{t∈T}Re∑_{ψ∈Ψ}ψ(e(t))G_{ψ}(y_{t}) ≤ E+2n_{T}mb/x. （1）
```

接下来要把这个特征和从点 `y_{t}` 移回共同的点 `x`，并用 `T` 的分布条件得到正合所需的权重 `c_ψ`。

## 第 5 节 · 把每项移到同一个 x

**自变量变动引理。** 存在绝对常数 `C_{d}≥0`，对每个上述有限群、任意局部数据 `D`、任意 `ℓ` 及所有 `y,z≥1`，有

```text
|G_{1}(y)−G_{1}(z)|≤C_{d}|y−z|,
|G_{ψ}(y)−G_{ψ}(z)|≤|y−z|[log max(y,z)+C_{d}+|ℓ(ψ)|] (ψ≠1).
```

这是本节引用的 `derivative_integral_all`。对于非平凡特征，它用到以模估计得到的 `∑_{n≤Y}Λ(n)/n≤log Y+O(1)`。对于平凡特征，同一类初等估计用于控制斜坡和的斜率减去 `log y−γ_{E}` 后的差。

令 `R` 大于或等于以下三数，其中 `r=|M₀|x^{−1+ε}`：

```text
C_{d},
log(x+1)+C_{d}+|K₀| + r x(log x+C_{d}+|K₀|),
log(x+1)+C_{d}+|C_{E}|log x.
```

**平凡特征。** 因 `|y_{t}−x|≤1`，逐项移到 `x` 时最多损失 `C_{d}`，因此 `∑_{t∈T}G_{1}(y_{t})≥n_{T}[G_{1}(x)−R]`。

**保留的非平凡特征。** 由 `ψ(1,0,0)=1`，`ψ(e(t))=χ_ψ(t)`。移到 `x` 的代价至多 `n_{T}[log(x+1)+C_{d}+|K₀|]`。对于移好后的和，要把 `∑_{t∈T}χ_ψ(t)` 换成 `n_{T}c_ψ`。若 `χ_ψ` 平凡，两者相等；若非平凡，差的模至多为 `n_{T}r`。由 `G_{ψ}(1)=ℓ(ψ)` 及自变量变动引理，有 `|G_{ψ}(x)|≤x[log x+C_{d}+|K₀|]`。故把上述两种误差加起来，取实部后得到

```text
∑_{t∈T}Re[ψ(e(t))G_{ψ}(y_{t})] ≥ n_{T}[c_ψ Re G_{ψ}(x)−R].
```

**未保留的特征。** 它们全是非平凡特征。对每个 `t`，先用 `Re z≥−|z|`，再用变动引理和 `|ℓ(ψ)|≤|C_{E}|log x`。逐项下界为 `−|G_{ψ}(x)|−R`。

三类加起来，得到（1）左边求和部分的下界 `n_{T}[G_{m}(x)−Σ(x)−|Ψ|R]`。

## 第 6 节 · 指数中的 3 从哪里来？

取 `A₁=5+C_{d}+|K₀|+|M₀|(4+C_{d}+|K₀|)+4|C_{E}|`。当 `x≥3` 时，有 `log x≤4x^{1/4}`、`log(x+1)≤5x^{1/4}`。加上 `rx=|M₀|x^{ε}`，上节的三数都可被 `R=A₁ x^{1/4+ε}` 控制。选取统一阈值，使 `x≥3`、`x^{1/4}≥|M₀|A₁`、`x^{3ε/8}≥26`。这只用到开头固定的参数。于是 `|Ψ|R≤x^{1/2+ε}`。记 `G=G_{m}(x)−Σ(x)`、`X=x^{1/2+ε}`，按原证明将这一误差放宽为 `4X`。把下界代入（1），令 `Q=n_{T}mb`，得

```text
Q(δ₂/2)(G−4X) ≤ E+2Q/x. （2）
```

由尺度条件，`Q>0`。归一化后，令 `Y=x^{1/2+13ε/8}`，逐项估计 `B_{E}/Q`。

- 第一项 `a_{E}/(mb) ≤ 2x/m ≤ 2X ≤ 2Y`，因为 `m≥x^{1/2−ε}`。
- 第二项 `a_{E} m/(kb) ≤ 2xm/k ≤ 2 ≤ 2Y`。
- 第三项 `2nmx^{ε}/n_{T} ≤ 4mx^{9ε/8} ≤ 4Y`，因为 `n/n_{T}≤2x^{ε/8}`，而 `m≤x^{1/2+ε/2}`。指数 `13ε/8` 出自这一项。
- 第四项 `(n₂/n_{T})(k/n²)x^{2ε} ≤ 2x^{1/2+9ε/8} ≤ 2Y`，使用 `n₂≤n` 和 `k≤n²x^{1/2−ε}`。

所以 `E/Q≤10x^{Cε}Y`。将（2）除以 `Q`，再利用 `2/x≤1≤x^{Cε}Y`，得 `δ₂(G−4X)≤22x^{Cε}Y`。因为 `δ₂≥x^{−ε}`，得到

```text
G ≤ 4X + 22x^{1/2+(C+21/8)ε} ≤ 26x^{1/2+(C+21/8)ε}.
```

最后用阈值条件 `26≤x^{3ε/8}`。将这个因子并入指数就得到 `G≤x^{1/2+(C+3)ε}`。还原 `G=G_{m}(x)−Σ(x)` 即证原命题。

## 第 7 节 · 逐点界怎样进入窗口判据？

在 `core_gm` 中，输入计数差的指数系数取 `C=e_{D}+e_{L}+3`，第五项由 `ch_top` 给出。后者使用数据把计数差变成同一组格和斜率估计的输出，并将该输出控制在 `x^{Cε}B_{E}`。因此本篇给出指数 `½+(e_{D}+e_{L}+6)ε` 加未保留特征的误差。[计数差界的证明](%E5%95%86%E6%A0%BC%E6%96%9C%E7%8E%87%E5%A6%82%E4%BD%95%E6%8E%A7%E5%88%B6%E8%AE%A1%E6%95%B0%E5%B7%AE.md)

随后 `gmA_eq` 按本原特征重新编号，把 `G_{m}(x)` 识别为层的加权素数和。`sigA_le` 对未保留特征逐个用显式公式条件，再用 `|Ψ|=4o`，得到 `Σ≤4o x^{1/2+ε}`。这里 `o` 是层的一个固定整数。故两项之和可以放在同一个较大幂次下，乘上 `1+4o`。固定 `ε>0` 后，对充分大的 `x` 有 `1+4o≤x^{ε}`。这样便得到 `½+(e_{D}+e_{L}+7)ε`。要得到整个窗口上的估计，还需要在窗口上**每个**充分大的点取得满足这些约束的数据。[主定理怎样提供并使用窗口条件](%E4%B8%BB%E5%AE%9A%E7%90%86%E5%A6%82%E4%BD%95%E4%BD%BF%E7%94%A8%E7%AA%97%E5%8F%A3%E4%BC%B0%E8%AE%A1.md) · [保留项与余项的证明](%E6%83%AF%E6%80%A7%E5%B9%B3%E5%9D%87%E6%80%8E%E6%A0%B7%E8%BF%98%E5%8E%9F%E7%8B%84%E5%88%A9%E5%85%8B%E9%9B%B7%E7%89%B9%E5%BE%81.md)
