# 有限矩阵群的阶怎样控制辅助分母

## 第 1 节 · 命题

对整数 `n≥0` 和素数 `p`，定义

```text
m_{p}(n)=∑_{i≥0}⌊n/(p^{i}(p−1))⌋， M(n)=∏_{p≤n+1}p^{mₚ(n)}。
```

和式只有有限项非零。**Minkowski 整除定理。** 对每个有限子群 `G⊂GL_{n}(ℚ)`，有 `|G|∣M(n)`。而且对所有 `n≥0`，`M(n)∣(2n)!`。下文证明这两个结论，再说明它们怎样给出项目中的分母大小界。

项目把 `M(n)` 记为 `minkM n`，把第一句对全部 `n` 的断言记为 `MinkDiv`。它被传给设计选择定理。那里真正要用的是一批辅助整数 `DGam` 的整除关系，从而使分母的素因子和对数大小均有统一控制。

## 第 2 节 · 用分圆多项式列出允许的迹

先假设 `P⊂GL_{n}(ℤ)` 是有限 `p` 群。令 `m=⌊n/(p−1)⌋`。任取 `g∈P`，它被某个 `X^{pᵃ}−1` 零化。该多项式在特征零没有重根，故 `g` 在复数上可对角化。其有理特征多项式中，第 `j` 类根（原始 `p^{j}` 次单位根）以整个不可约分圆因子 `Φ_{pʲ}` 出现。记其重数为 `b_{j}`，其中 `j=0` 指根 1。

原始 `p` 次单位根之和为 `−1`。而 `j≥2` 时，`Φ_{pʲ}(X)=∑_{i=0}^{p−1}X^{i pʲ⁻¹}` 的次高次项系数为零，故根的和为零。于是 `tr(g)=b₀−b₁`，并有

```text
n−tr(g)=p b₁+∑_{j≥2}p^{j−1}(p−1)b_{j}=p y。
```

这里 `y≥0` 是整数。要见 `y≤m`，比较 `(p−1)y` 和 `n` 的各项即可。第一项恰是 `(p−1)b₁`，后面每项至多等于它对应的特征多项式次数。如果 `y=0`，则 `b_{j}=0` 对 `j≥1` 都成立，可对角化性随即给出 `g=1`。所以非单位元的迹必落在 `n−p,n−2p,…,n−mp` 中。

## 第 3 节 · 张量幂使迹的多项式和可以整除

对任意 `k≥0`，在 `(ℚ^{n})^{⊗k}` 上取算子 `E=|P|^{−1}∑_{g∈P}g^{⊗k}`。这里 `k=0` 用一维平凡表示。左乘任一 `h^{⊗k}` 只重新排列和式中的项，故 `E²=E`。投影的迹是其像的维数，因而是整数。又因为张量积的迹等于各因子的迹的乘积，

```text
|P| ∣ ∑_{g∈P}tr(g)^{k}。
```

对 `k` 取整数线性组合，可知 `|P|∣∑_{g∈P}F(tr(g))` 对每个 `F∈ℤ[X]` 成立。取

```text
F(X)=∏_{j=1}^{m}(X−(n−pj))。
```

上一步列出的所有非单位元迹都是 `F` 的根。和式只剩单位元一项 `F(n)=p^{m}m!`。所以 `|P|∣p^{m}m!`。由 Legendre 公式，后者的 `p` 进赋值是 `m+∑_{i≥1}⌊m/p^{i}⌋=m_{p}(n)`。

现在取任意有限 `G⊂GL_{n}(ℤ)`，对每个 `p` 把上述结论用在 Sylow `p` 子群。其阶正是 `p^{vₚ(|G|)}`，故 `v_{p}(|G|)≤m_{p}(n)`。这就证明了整系数版本。

## 第 4 节 · 选取不变格，再用阶乘比较

若 `G⊂GL_{n}(ℚ)` 有限，取全部标准基向量的 `G` 轨道生成的 `ℤ` 模 `L=∑_{g∈G}gℤ^{n}`。它有限生成、无挠，而且包含标准基并处在 `ℚ^{n}` 中，所以是秩 `n` 的自由 `ℤ` 模。每个 `g` 及其逆均保持 `L`。在 `L` 的整基上写矩阵便得到 `G` 在 `GL_{n}(ℤ)` 中的同构像。整系数版本给出相同的整除结论。

再注意 `p≤2(p−1)`，所以每一项都有

```text
⌊n/(p^{i}(p−1))⌋≤⌊2n/p^{i+1}⌋。
```

右侧对 `i≥0` 求和就是 `v_{p}((2n)!)`，故 `M(n)∣(2n)!`。尤其当 `n≥1` 时，`log M(n)≤log((2n)!)≤2n log(2n)`。`n=0` 时两个整数都等于 1。

## 第 5 节 · 为什么可以统一取常数 12

设给定一个项目数据族，令 `x` 为尺度、`i` 为其中的行、`u` 为该行的词指标。记 `A=fN(m)≥2`，这里 `f` 是项目的偶数域次数参数，`N(m)` 是对应维数。假设存在 `x₀`，使每个 `x≥x₀` 和每个该处的 `i,u` 都有 `D_{Γ}∣M(2A)`。这正是 `DGamDvdF`。于是 `D_{Γ}>0`，其素因子不超过 `2A+1`，而且

```text
log D_{Γ} ≤ log M(2A) ≤ 4A log(4A) ≤ 12A log A。
```
