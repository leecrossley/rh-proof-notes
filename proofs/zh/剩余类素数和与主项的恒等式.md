# 剩余类素数和与主项的恒等式

## 第 1 节 · 黎曼猜想 · 窗口估计中的有限傅里叶展开

逐点估计中要控制一个算术量与它的主项之差。Lean 的 `Deduction.ch_balance` 先给出这个差的精确公式：它等于一组带冯·曼戈尔特权重的特征和。这个公式解释为什么对若干同余类计数，能够约束 ζ 和狄利克雷特征对应的加权素数和。

### 有限群和局部数据

取任意有限交换群 `H`，记 `A=(ℤ/2ℤ)²×H`，写元素为 `(i,j,h)`。这里的 `A` 对应 Lean 的 `E0 × H`。记 `Φ = {(0,j,h)}`、`Φ^{c} = {(1,j,h)}`，`f=|Φ|=2|H|`。`Â` 表示 `A` 的全部复值加法特征，乘法记号下平凡特征为 `1`（Lean 写作 `0`）。定义 `c(i,j,h)=(-1)^{i}` 和配对映射 `P_{t}(g)=g+(1,1,t)`。对每个 `t∈H`，`P_{t}` 把 `Φ^{c}` 双射到 `Φ`。

局部数据包括两个自然数 `q₁,d`，以及对每个自然数 `p` 指定的子群 `I_{p} ≤ A` 和元素 `F_{p}∈A`。在来自数域的应用里，它们分别记录惯性子群和 Frobenius 的代表元。本段只用以下条件（`HostFactsS`）。有有限集 `S⊆ℕ`，包含 `2,q₁`。数 `d` 是素数且 `d∉S`。若 `p` 为素数且 `p∉S∪{d}`，则 `I_{p}={0}`。若 `p∈S`，则 `I_{p}⊆Φ`、`F_{p}∈Φ`。在 `d` 处，`I_{d}={0,(1,0,0)}`。

给定 `ψ∈Â`，以陪集上的平均值定义它的局部系数。对 `n≥1`，令 `P_{ψ}(n)` 是下式。只在素数幂上用到它，此时乘积只有一项。

```text
P_{ψ}(n) = ∏_{p∣n} [ |I_{p}|^{−1} ∑_{h∈I_{p}} ψ(v_{p}(n)F_{p}+h) ].
```

固定任意函数 `ℓ:Â→ℂ`。对 `y>0`，记 `U_{ψ}(y)=∑_{1≤n≤y}Λ(n)P_{ψ}(n)(y/n−1)`。定义去掉主项后的量

```text
G_{1}(y)=U_{1}(y)−y log y+(1+γ_{E})y,
G_{ψ}(y)=U_{ψ}(y)+yℓ(ψ) (ψ≠1).
```

这里 `Λ` 是冯·曼戈尔特函数，`γ_{E}` 是欧拉常数。由于 `P_{1}(n)=1`，平凡特征项就是 ζ 的斜坡素数和扣除主项。在 `P_{ψ}` 由本原狄利克雷特征给出的应用中，`ℓ(ψ)` 取该特征在 1 处的 `L′/L`。

## 第 2 节 · 同余类计数怎样读成特征和？

给定 `a>0`、`t∈H`、非负整数 `N` 和函数 `w:A→ℝ`，使所有 `ρ∈Φ` 都有 `0<w(ρ)` 和 `a/w(ρ)≤N`。记 `w_{g}=w(P_{t}(g))`、`z_{+}=max(z,0)`。带尺度的计数 `A_{t}`（`ASK`）由两部分相加得到。

```text
∑_{p≤N，p 素数，p∉{2,q₁,d}，F_{p}∉Φ} (2 log p)∑_{1≤i≤N，iF_{p}∈Φ^{c}}(a/p^{i}−w_{iF_{p}})_{+}
+ (log d)∑_{1≤i≤N}∑_{g∈(iF_{d}+I_{d})∩Φ^{c}}(a/d^{i}−w_{g})_{+}.
```

前一项对一般素数按 `iF_{p}` 落入的类取权重，后一项在特殊素数 `d` 处用惯性陪集取权重。相应主项 `M(a,w)`（`MAIN`）为

```text
M(a,w)=a[log a−1−γ_{E}+ℓ(c)−f^{−1}∑_{ρ∈Φ}log w(ρ)].
```

**定理。** 对所有满足第 1 节局部条件、以及上述 `a,t,N,w` 条件的数据，都有复数等式

```text
A_{t} − M(a,w) = f^{−1}∑_{g∈Φ^{c}}∑_{ψ∈Â} ψ(−g) w_{g}G_{ψ}(a/w_{g}).
```

等号右端就是 `De`。计数一项 `A_{t}` 是实数，在这个等式中视为复数。

### 证明的第一步 用正交关系读取陪集

给定素数幂 `p^{i}`（`i≥1`），考虑它对类 `g∈A` 的贡献的归一化傅里叶和。交换有限求和顺序得

```text
K(p^{i},g) := f^{−1} ∑_{ψ∈Â} ψ(−g)P_{ψ}(p^{i})
= (f|I_{p}|)^{−1}∑_{h∈I_{p}}∑_{ψ∈Â}ψ(iF_{p}+h−g).
```

在 `z=0` 时，`∑_{ψ∈Â}ψ(z)=|A|=2f`。在 `z≠0` 时，有限交换群的特征可以分离点。选一个满足 `ψ₀(z)≠1` 的特征，用 `ψ↦ψψ₀` 重排求和，就得到该和等于零。因此

```text
K(p^{i},g) = [2/|I_{p}|] · 1_{g∈iF_{p}+I_{p}}.
```

因子 2 来自 `|A|/|Φ|`。在无分歧素数处只剩一个点，在 `d` 处每个陪集元素取得系数 1。这就是计数里两种不同系数的来源。

## 第 3 节 · 计数与斜坡和如何相等？

将上节的正交关系用于下面的式子。先对 `ψ` 求和，再把 `n` 的和按素数幂整理。

```text
F := f^{−1}∑_{g∈Φ^{c}}∑_{ψ∈Â} ψ(−g) ∑_{1≤n≤N}Λ(n)P_{ψ}(n)(a/n−w_{g})_{+}
= ∑_{p 素数，p^{i}≤N}(log p)∑_{g∈Φ^{c}}K(p^{i},g)(a/p^{i}−w_{g})_{+}.
```

这里 `i` 取正整数。凡 `p^{i}>N` 的项一概为零，因为 `a/w_{g}≤N`。所以对 `p≤N`，内层可遍历 `1≤i≤N` 而不改变总和。现在逐类处理素数。

**一、`p∈S`。** 因为 `F_{p}∈Φ`、`I_{p}⊆Φ`、且 `Φ` 是子群，`iF_{p}+I_{p}` 不会与 `Φ^{c}` 相交。因此这类素数不贡献。计数 `A_{t}` 也不计入这些素数，因为它要求 `F_{p}∉Φ`。

**二、`p∉S∪{d}`。** 此时 `I_{p}={0}`，陪集退化为点 `iF_{p}`。只有 `iF_{p}∈Φ^{c}` 时才贡献，系数是 `2 log p`。若 `F_{p}∈Φ` 则所有倍数都在 `Φ`，可以把这些 `p` 整体去掉。由于 `2,q₁∈S`，剩下的恰好是 `A_{t}` 的第一项。

**三、`p=d`。** 此时 `|I_{d}|=2`，所以系数为 `log d`。对陪集 `iF_{d}+I_{d}` 中落在 `Φ^{c}` 的元素求和，正是 `A_{t}` 第二项。若 `d>N`，这一项也因截断条件为零。

由此 `F=A_{t}`。另一方面，令 `y=a/w_{g}`。在内层和中，`(a/n−w_{g})_{+}=w_{g}(y/n−1)_{+}`，截断 `N` 已覆盖所有可能非零的项。因此内层和等于 `w_{g}U_{ψ}(y)`。代入第 1 节的定义可写成

```text
w_{g}U_{ψ}(a/w_{g}) = w_{g}G_{ψ}(a/w_{g}) + { a[log a−log w_{g}−1−γ_{E}]，若 ψ=1；
−aℓ(ψ)，若 ψ≠1。 }
```

等式第一项求和，就得到命题右边。余下修正项求和得到下一页的主项。

## 第 4 节 · 主项里为什么只有一个非平凡特征？

`Φ^{c}` 是 `Φ` 的一个陪集。如果 `ψ` 在 `Φ` 上非平凡，则 `∑_{g∈Φ^{c}}ψ(−g)=0`。这是因为存在 `h∈Φ` 使 `ψ(−h)≠1`，用 `g↦g+h` 重排求和即可。若 `ψ` 在 `Φ` 上平凡，它便从二元商群 `A/Φ` 得到，只有两个可能。`ψ=1` 时该和等于 `f`，`ψ=c` 时该和等于 `−f`。

于是所有非平凡特征的修正项 `−aℓ(ψ)` 经过傅里叶加权及除以 `f` 后，只留下 `aℓ(c)`。平凡特征的修正项贡献

```text
a[log a−1−γ_{E}−f^{−1}∑_{g∈Φ^{c}}log w_{g}].
```

利用 `P_{t}:Φ^{c}→Φ` 是双射，最后一项可改成对 `ρ∈Φ` 的和。把两类修正项相加，正好等于 `M(a,w)`。由 `F=A_{t}`，得到 `A_{t}−M(a,w)` 的等式，证毕。

后面用到的是该等式的实部。对一批不同的 `a,t,w` 求和后，左边是需要外部算术估计控制的总差（`gapA`），右边可再对群的平移求平均。这样既能压低权重变化的误差，也能留下指定的加权特征和。[继续读平移平均的证明](%E5%B9%B3%E7%A7%BB%E5%B9%B3%E5%9D%87%E5%A6%82%E4%BD%95%E7%BB%99%E5%87%BA%E7%B4%A0%E6%95%B0%E5%92%8C%E7%9A%84%E9%80%90%E7%82%B9%E4%BC%B0%E8%AE%A1.md)
