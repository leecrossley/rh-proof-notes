# 主定理如何使用窗口估计

## 第 1 节 · 黎曼猜想 · 从 Main.lean 读到加权素数和

源码最终从所有本原狄利克雷特征的右半平面无零点性推出 RH。为了研究一个固定的本原特征，作者先把它的各次幂收进同一个有限族，然后对这个族的一条加权素数和应用窗口判据。下面翻译这段推理，并在后面写清楚源码从哪里取得窗口和估计所需的数据。[中文阅读入口](../../README.zh-CN.md)

### 选定要估计的量

固定模 `N ≥ 1` 的本原特征 `ψ`，令 `o` 是它在模 `N` 特征群中的阶。对 `0 ≤ j < o`，取诱导 `ψ^{j}` 的唯一本原特征。把所得本原特征去重，记成有限集 `𝓛_{ψ}`。这就是源码的 `Level.cyc ψ`。它含 `ψ` 和模 1 的平凡特征 `𝟙`。记 `G_{χ}(y)` 为从斜坡加权和 `∑_{1≤n≤y} Λ(n)χ(n)(y/n−1)` 减去相应主项后的量。对于 `𝟙` 减的是 `y log y−(1+γ_{E})y`，对于非平凡特征减的是 `−y L′(1,χ)/L(1,χ)`。[主项与变换公式](%E4%BB%8E%E5%8A%A0%E6%9D%83%E7%B4%A0%E6%95%B0%E5%92%8C%E5%88%B0%E6%9E%81%E7%82%B9-%E7%95%99%E6%95%B0%E4%B8%BA%E4%BD%95%E4%B8%8D%E6%8A%B5%E6%B6%88.md)

```text
G_{𝓛}(y) = G_{𝟙}(y) + 1/(3o+1) · ∑_{χ∈𝓛_{ψ}∖{𝟙}} Re G_{χ}(y).
```

这里权重取自源码的 `Level.wt`。一般的层可以把一个指定的非平凡特征也赋权 1；循环层 `Level.cyc` 的指定项为空。

**窗口条件推出无零点。** 固定 `λ > 1` 和实常数 `B`、`ε₁ > 0`。若对每个 `0 < ε < ε₁` 以及每个实阈值 `T`，存在 `Y ≥ T` 使 `G_{𝓛}(y) ≤ y^{1/2+Bε}` 在整个 `[Y,Y^{λ}]` 上成立，则 `L(s,ψ) ≠ 0` 对所有 `Re s > 1/2` 成立。

任取 `Re s = β > 1/2`，令 `d = ½ min{β−½, ½}` 和 `θ = ½+d`。选 `ε = min{ε₁/2, d/(|B|+1)}`，则 `0 < ε < ε₁`，`Bε ≤ d`。把窗口选在 `Y ≥ 1` 后，就有 `G_{𝓛}(y) ≤ y^{θ}`。窗口引理排除族中每个 `L` 函数在 `Re z > θ` 的零点。因为 `ψ ∈ 𝓛_{ψ}` 且 `β > θ`，所以 `L(s,ψ) ≠ 0`。[窗口引理详证](Landau%E7%AA%97%E5%8F%A3%E5%BC%95%E7%90%86-%E5%8D%95%E4%BE%A7%E4%B8%8A%E7%95%8C%E5%A6%82%E4%BD%95%E6%8E%92%E9%99%A4%E6%9E%81%E7%82%B9.md)

## 第 2 节 · 窗口估计的量词怎样接上？

在最上层，作者取固定的 `λ=3/2`。下面按 `zeroFreeAll_of_topG` 的顺序读。给定一个本原特征 `ψ`，先把 `GChi ψ` 理解为对一个候选的两条要求。第一条是该候选满足循环层的特征分布及显式公式条件 `EAtH`，其中对数导数界的常数取 4。第二条是该候选的数域 `E` 在截断整数 `t` 处满足同调长度界 `VVle(E,t,√b)`，`b` 是这个候选的尺度。后一条在第 3 节写成公式。

`(GChi ψ).cls λ` 是满足以下要求的数据族 `F` 的类。族的可用点集 `W_{F}` 包含任意远的完整窗口 `[Y,Y^{λ}]`。当 `x` 超过族的起始阈值 `x₁` 后，`F` 在 `x` 处的每个候选都满足上面的两条要求。候选的实际尺度在这些点上等于 `x`，而精度参数始终等于该族的 `ε`。

由第二条，对类中的每一族，取阈值 `x₁+1`，即可得到族上统一的同调长度条件（`hypV_of_cls`）。同时，由第一条和尺度相等，也得到 `EFamC`（`eFamC_of_cls`），即存在常数 `C` 及阈值 `x_{E}`，对所有 `x ≥ x_{E}` 的所有候选均有 `EAtH`。此处实际可取 `C=4`、`x_{E}=x₁+1`。

**此处使用的构造接口。** `TopG` 对任意 `λ > 1` 和任意逐点要求 `P` 给出以下蕴含。若已有满足 `P` 的窗口基础数据（`HostExW λ P.req`），且所有属于 `P` 所规定类的族都最终逐候选满足同调长度界，则存在固定的 `e_{D}, e_{L}, ε₁`，其中 `ε₁ > 0`。对每个 `0 < ε < ε₁`，可找到该类中的一族 `F`、实常数 `K,c_{HH},e_{K},C_{L}` 及阈值 `x₀`，使每个 `x ∈ W_{F}` 且 `x ≥ x₀` 都有一份 `ChainTied` 数据。它将族中的格、局部数据和加权素数和的参数配成同一份可用于估计的数据，损失指数受上述固定的 `e_{D},e_{L}` 控制。

把 `P` 取为 `GChi ψ`，并代入已有的窗口基础数据。取接口给出的族 `F`。上文的 `EFamC` 保证所有充分大的候选都满足第一组条件。每个窗口上的大点，用 `tiedCore_of_chainTied` 从相应的 `ChainTied` 数据取出一个满足 `CoreAtH` 的候选。于是同一个候选同时满足两组条件。使用 `core_gm` 并取三道阈值的最大值，对充分大的窗口点得到

```text
G_{𝓛}(x) ≤ x^{1/2+(e_{D}+e_{L}+7)ε}.
```

`e_{D},e_{L}` 在 `ε` 之前选定，故第 1 节可取 `B=e_{D}+e_{L}+7`。主线实际取 `e_{D}=2,e_{L}=0`，因此指数是 `1/2+9ε`。族的窗口性保证能越过任意固定阈值。由此得到每个本原特征在右半平面的无零点性。[窗口归约的原讲义](%E4%BB%8E%E7%AA%97%E5%8F%A3%E4%BC%B0%E8%AE%A1%E5%88%B0%E9%BB%8E%E6%9B%BC%E7%8C%9C%E6%83%B3.md) · [逐点上界的证明](%E5%B9%B3%E7%A7%BB%E5%B9%B3%E5%9D%87%E5%A6%82%E4%BD%95%E7%BB%99%E5%87%BA%E7%B4%A0%E6%95%B0%E5%92%8C%E7%9A%84%E9%80%90%E7%82%B9%E4%BC%B0%E8%AE%A1.md) · [主线常数怎样选定](%E4%B9%9D%E9%A1%B9%E7%AE%97%E6%9C%AF%E6%9D%A1%E4%BB%B6%E6%80%8E%E6%A0%B7%E8%90%BD%E5%9C%A8%E5%90%8C%E4%B8%80%E4%B8%AA%E6%95%B0%E6%8D%AE%E6%97%8F%E4%B8%8A.md)

## 第 3 节 · 窗口基础数据需要什么？

`VWin` 的内容是一个带窗口的伽罗瓦上同调长度估计。为说明它约束的对象，固定数域 `E`、素数 `ℓ`，取代码允许的一套局部数据，包括 `E` 的代数闭包、`ℓ` 上方各处的延拓以及圆分特征。用 `G_{E,S}` 表示在有限处 `S` 外不分歧的最大扩张的伽罗瓦群，其中 `S` 是 `ℓ` 上方的有限处集。用 `G_{v}` 表示相对于所选延拓的分解群。`shaLen` 是下列局部化映射的核作为 `ℤ_{ℓ}` 模的长度。系数 `ℚ_{ℓ}/ℤ_{ℓ}` 上的作用由圆分特征的 `−e` 次幂给出。

```text
H^{1}(G_{E,S}, ℚ_{ℓ}/ℤ_{ℓ}(−e)) → ∏_{v∈S} H^{1}(G_{v}, ℚ_{ℓ}/ℤ_{ℓ}(−e)).
```

记该长度为 `l_{E,ℓ,e}`。`VVle E t B` 要求对任意代数闭包及每个 `ℓ` 的任意允许局部数据，所有 `1 ≤ e < t` 的长度有限，并且对每个有限素数集 `S′` 都有 `∑_{ℓ∈S′}(log ℓ)∑_{1≤e<t}l_{E,ℓ,e} ≤ B`。

`VWin` 对每个本原 `ψ`、`0 < ε < 1/52` 及每个整数值选阶函数 `e(x)`（对全部 `x ≥ 1` 满足 `x^{2+8ε} ≤ 2^{e(x)} ≤ 2x^{2+8ε}`）要求如下。存在 `J ≥ 1` 与 `X₀`，使每个 `X ≥ X₀` 和在尺度 `U=X^{1/J}` 上可用的素数对 `q,d`，都可选到 `Y ≥ U`、`Y² ≤ X`。对所有 `x ∈ [Y,Y²]` 与每个相应的圆分子域 `E`，有

```text
VVle(E, ⌊x^{401}⌋, exp(x^{ε}/2)).
```

这里“可用”指 `q≡3 (mod 8)`、`d≡7 (mod 16)`，`log q` 在 `(U^{ε/5}/2,U^{ε/5}]`，`log d` 在 `(U^{ε/5}(log U)²/2,U^{ε/5}(log U)²]`，且 `q` 与所有不超过 `U^{ε/5}` 的奇素数均整除 `d+1`。圆分子域的定义是，存在一个圆分域 `ℚ(ζ_{M})`，其中 `M` 同时为 `2^{e(x)+2},N,q,d` 的倍数，使 `E` 嵌入为下述子群的固定域。以 `a` 表示自同构 `ζ_{M} ↦ ζ_{M}^{a}`，要求 `a≡±1 (mod 2^{e(x)+2})`、`ψ(a)=1`，且 `(a/q)=(a/d)=1`。

`supplyChi` 通过 `supplyOfAdm` 取得第 2 节的窗口基础数据。它将这个长度估计、辅助素数的解析估计和由 `admissibleClassesTwistedChar` 提供的秩存在性接到一起。源码中的结论为，每个 `0 < ε < 1/52` 可一次选定 `C_{T2},C₈,C₅,c₆,C_{b},x₀`（`C₈≥1, C₅,c₆,C_{b}>0`）及一族尺度窗口。对每个属于该族、且 `x ≥ x₀` 的尺度，可选到满足基本秩与宿主条件的 `(R,H,q₀)`，并使该候选满足 `GChi ψ`。此处的秩、素数与宿主条件分别由 `RankVal`、`HostGood` 规定。本篇在这里引用这项构造结论。[两类估计如何共用一个窗口](%E6%80%8E%E6%A0%B7%E8%AE%A9%E4%B8%8A%E5%90%8C%E8%B0%83%E7%95%8C%E5%92%8C%E6%89%AD%E6%9B%B2%E4%BC%B0%E8%AE%A1%E5%85%B1%E7%94%A8%E4%B8%80%E4%B8%AA%E7%AA%97%E5%8F%A3.md)

## 第 4 节 · 模数变换与函数方程

先把右半平面无零点性从本原特征推广到任意模 `N ≥ 1` 的特征 `χ`。记 `χ*` 为诱导它的本原特征，导子整除 `N`。对 `Re s > 1/2`，且在 `χ` 为主特征时要求 `s ≠ 1`，提高模数的公式给出

```text
L(s,χ) = L(s,χ*) ∏_{p∣N} [1−χ*(p)p^{−s}].
```

这个等式在绝对收敛半平面中由欧拉乘积得到，再延拓到所需的区域。若 `χ*` 为主特征，则诱导出的 `χ` 也是主特征，因此公式在此处确实避开了 `s=1` 的极点。对于每个因子，`|χ*(p)p^{−s}| ≤ p^{−Re s} < 1`，所以因子非零。第一项也由本原特征的结论非零。这就是源码的 `EveryCharacter`。普通 RH 只需其中模 1、取平凡特征的一例。

于是 `ζ(s) ≠ 0` 对 `Re s > 1/2`、`s ≠ 1` 成立。设 `s` 是 ζ 的非平凡零点且 `Re s < 1/2`。由 `ζ(0) = −1/2` 得 `s ≠ 0`。令 `z=1-s`，则 `Re z > 1/2` 且 `z ≠ 1`。Lean 使用的函数方程是

```text
ζ(1−z) = 2(2π)^{−z} Γ(z) cos(πz/2) ζ(z).
```

常数及幂非零，`Γ(z)` 在 `Re z > 0` 非零。余弦若为零，则 `z=2k+1`，其中 `k` 为整数；由 `Re z > 1/2` 得 `k ≥ 0`。`k=0` 会给出 `s=0`，而 `k ≥ 1` 会给出平凡零点 `s=−2k`。两种情形均已排除。最后一项 `ζ(z)` 也非零，于是 `ζ(s) ≠ 0`，矛盾。由于临界线右侧已排除，非平凡零点都在 `Re s=1/2`。

### 主声明怎样取得第 2 节的构造接口
