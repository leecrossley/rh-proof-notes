# 怎样用狄利克雷多项式数出坏扭曲

## 第 1 节 · 命题 · 稀少的坏扭曲

固定 `σ₀=1−1/400`。对每个正整数 `f`，把模 `f` 的本原狄利克雷特征按它们的导子区别开。给定实数 `Q≥3`，考虑所有满足以下条件的本原特征 `χ`：导子 `f≤Q`，且 `L(s,χ)` 在 `Re s>σ₀`、`|Im s|≤Q` 内至少有一个零点。

**定理。** 存在绝对常数 `C>0`，对每个 `Q≥3`，上述特征的个数至多为 `CQ^{1/4}`。

**推论。** 对任意实数 `F`，设有限素数集 `P` 的每个 `p` 都满足 `p>F`，并且存在正整数 `a≤F` 和导子为 `ap≤Q` 的本原特征，在同一矩形内有零点。则 `|P|≤CQ^{1/4}`。

这是 `zero_density_box` 和 `QH.count_bad`。定理只数出现过零点的特征，每个特征只需要选一个零点。推论在筛选辅助素数时使用，给出第一类坏素数的上界。[怎样筛去两类坏素数](%E6%80%8E%E6%A0%B7%E6%8C%91%E5%87%BA%E5%90%8C%E6%97%B6%E6%BB%A1%E8%B6%B3%E6%89%AD%E6%9B%B2%E4%BC%B0%E8%AE%A1%E7%9A%84%E7%B4%A0%E6%95%B0%E5%AF%B9.md)

证明用到经典非消失定理：任一非主狄利克雷特征的 `L` 函数在 `Re s≥1` 非零。它只用来保证选出的零点实部小于 1。主特征只有导子 1 的那个是本原的，最后可以单独加上至多一项。

## 第 2 节 · 每个零点迫使一个有限和偏大

只须先处理足够大的 `Q≥20`。置 `X=⌈Q⌉`、`Y=X⁴`、`J=8(⌊log₂ X⌋+1)`、`N=2^{J}`。有 `N≥X⁸`。对满足条件的导子 `f>1` 的本原特征 `χ`，选一个零点 `ρ`，记 `σ=Re ρ`。由于 `χ` 非主，它的完整模 `f` 周期和为零，任何前缀和的绝对值至多为 `f`。对 `n^{−s}` 作部分求和，这既给出 `Re s>0` 内局部一致收敛的狄利克雷级数，又在 `s=ρ` 给出截断余项界

```text
|L(ρ,χ)−∑_{n≤N}χ(n)n^{−ρ}| ≤ 2f N^{−σ}(1+|ρ|/σ)。
```

这里尾部的部分和至多为 `2f`，导数绝对值是 `|ρ|t^{−σ−1}`。级数在 `Re s>1` 与原 `L` 函数一致，因此在 `Re s>0` 也一致。由 `L(ρ,χ)=0`、`1+|ρ|/σ≤3X`、`σ>15/16`，可知截断和 `P(ρ)` 至多为 `6X²N^{−15/16}`。故 `Y|P(ρ)|≤6X^{−3/2}≤1/2`。

记 `M(ρ)=∑_{d≤Y} μ(d)χ(d)d^{−ρ}`，这里 `μ` 是 Möbius 函数。因为 `|M(ρ)|≤Y`，有 `|P(ρ)M(ρ)|≤1/2`。将乘积展开，系数为 `a(n)=∑_{d∣n,d≤Y,n/d≤N}μ(d)`。对于 `1≤n≤Y`，全部因子都满足两个截断条件，因此系数在 `n=1` 处是 1，在其余整数上是 0。于是

```text
P(ρ)M(ρ)=1+∑_{Y<n≤YN}a(n)χ(n)n^{−ρ}。
```

右边的有限和绝对值至少为 `1/2`。把它拆成 `J` 个区间 `(U,2U]`，其中 `U=Y2^{j}`、`0≤j<J`。由三角不等式，至少有一块上的和 `B_{U}(χ,ρ)` 满足 `|B_{U}(χ,ρ)|≥1/(2J)`。

## 第 3 节 · 同一块内，来自不同特征的向量近乎正交

固定 `U`，用 `T` 表示在这一块满足上述界的一个本原特征集，每个特征 `χ` 已选定一个这样的 `ρ_{χ}`。对 `U<n≤2U`，令

```text
b(n)=a(n)n^{−σ₀}， v_{χ}(n)=χ(n)n^{−(ρ_{χ}−σ₀)}。
```

于是 `B_{U}(χ,ρ_{χ})=∑_{n}b(n)v_{χ}(n)`。每个 `|v_{χ}(n)|≤1`，所以 Gram 矩阵的对角项最多为 `U`。

对两个不同的本原特征 `χ,ψ`，模各自导子 `f,g`，在模 `fg` 的单位群上，`χ·\overline{ψ}` 非主。否则两者在此共同模数上相同，取本原化便相同。所以这个乘积的完整周期和为零，前缀和由 `fg` 控制。令 `w=(ρ_{χ}−σ₀)+\overline{(ρ_{ψ}−σ₀)}`。则 `Re w>0`、`|w|≤1+2Q`。把乘积与 `n^{−w}` 相乘再作部分求和，两个端点之和至多 `2fg`，积分项至多 `fg|w|log 2`。因此

```text
|∑_{U<n≤2U}v_{χ}(n) \overline{v_{ψ}(n)}| ≤ 2fg(1+|w|) ≤8Q³。
```

下面的有限维不等式把这两条相关性界用于整族。对任意有限向量族 `v_{i}`，若 Gram 矩阵每行的绝对值和 ≤ `Δ`，则 `∑_{i}|∑_{n}b(n)v_{i}(n)|²≤Δ∑_{n}|b(n)|²`。因为对任意系数列 `c_{i}`，展开 `‖∑_{i}c_{i}v_{i}‖²`，逐项用 `2|c_{i}c_{j}|≤|c_{i}|²+|c_{j}|²`，再使用行和与列和的界，得到 ≤ `Δ∑_{i}|c_{i}|²`。由欧氏范数的对偶表示，得到所需不等式。这里取 `Δ=U+8Q³|T|`。

## 第 4 节 · 为什么指数可以压到四分之一？

因为 `|a(n)|≤τ(n)`（`τ(n)` 为约数个数），对绝对常数 `A>0` 有 `∑_{U<n≤2U}|b(n)|²≤A U^{−197/200}`。具体说，`τ(n)≤C_{η}n^{η}` 对每个 `η>0` 成立：对足够大的素数 `p`，有 `k+1≤2^{k}≤p^{ηk}`，其余有限个素数各用 `sup_{k≥0}(k+1)p^{−ηk}<∞` 吸收到常数中。取 `η=1/200` 和 `σ₀=399/400`，逐项求和得到指数 `1+2η−2σ₀=−197/200`。

将上一页的有限维不等式与每项 `|B_{U}|≥1/(2J)` 合用，得

```text
|T|/(4J²) ≤ A U^{3/200} + 8Q³ A U^{−197/200}|T|。
```

由于 `U≥Y≥Q⁴`、`J=O(log Q)`，右边乘 `|T|` 的系数为 `O(Q^{−47/50})`，对足够大的 `Q` 至多为 `1/(8J²)`。移项后有 `|T|≤8AJ² U^{3/200}`。

将每个特征分配给一个检测它的块。最大的块起点至多为 `Y2^{J}≤2⁸X^{12}=O(Q^{12})`。把 `J` 个块的计数上界相加，再计入导子 1 的至多一个特征，总数为

```text
1+O((log Q)³ Q^{9/50}) = O(Q^{1/4})，
```

因为 `1/4−9/50=7/100>0`。剩下有界范围的 `Q≥3` 只涉及有限个模数和特征，可增大同一个常数覆盖。

对推论，每个坏素数 `p` 任选一个见证本原特征。若 `p,p′` 选中同一个特征，其导子有 `ap=a′p′`。若 `p≠p′`，必有 `p∣a′`，但 `1≤a′≤F<p`，矛盾。这给出从坏素数到上述本原特征集的单射。
