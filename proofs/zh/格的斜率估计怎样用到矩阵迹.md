# 格的斜率估计怎样用到矩阵迹？

## 第 1 节 · 命题 · 有限维矩阵的一条完整引理

在从斜率到计数差的证明中，有一条输入把许多局部格的秩加权平均斜率同一个全局格的斜率比较。它要求在复数处有一族矩阵，且这些矩阵满足两条定量的近似正交条件。实际数据先给出较大的矩阵，再从每个矩阵的定义域裁掉一个小维数的子空间。本篇证明裁剪后，两条近似正交条件还能保留多少。

取有限集 `I`，非负整数 `D,d_{i},r_{i}`。给定复矩阵 `B_{i}`（`D×d_{i}`）和 `V_{i}`（`d_{i}×r_{i}`），满足 `V_{i}^{*}V_{i}=I_{r_{i}}`。这里星号表示共轭转置。取权重 `g_{i}≥0`，令 `A_{i}=√g_{i} B_{i}`、`C_{i}=A_{i}V_{i}`，并定义

```text
Q=∑_{i}A_{i} A_{i}^{*}, Q′=∑_{i}C_{i} C_{i}^{*}, R=∑_{i}d_{i}, R′=∑_{i}r_{i}.
```

记 `‖M‖_{F}²=∑_{a,b}|M_{ab}|²` 为矩阵的 Frobenius 范数平方。给实数 `D_{*},σ,η₀,η₁,e₀,δ` 满足

```text
D_{*}>0, 0<σ≤1/20, D_{*}/σ≤R,
−1≤η₀≤σ/2, η₁≤σ/2, 0≤e₀, √e₀≤σ/2, 0≤δ≤1/4.
```

要求裁掉的总维数不超过 `δR`，即 `R−R′≤δR`。矩阵给出三条输入（`InputSG`）。

```text
‖A_{i}^{*}A_{j}‖_{F}² ≤ (1+η₀)d_{i} d_{j}/D_{*} (i≠j),
‖A_{i}^{*}A_{i}−I_{d_{i}}‖_{F}² ≤ e₀d_{i} (各 i), D≤(1+η₁)D_{*}.
```

**定理。** 对上述任意数据，有 `D>0`、`R′>0`、`2e₀≤1/4`，且

```text
tr(Q′²) ≤ (1+5σ+3√δ)(tr Q′)²/D,
∑_{i}‖C_{i}^{*}C_{i}−I_{r_{i}}‖_{F}² ≤ 2e₀R′.
```

## 第 2 节 · 裁剪后，哪些量只会变小？

写 `a=√e₀`。对任意方阵 `K`，用矩阵内积的 Cauchy–Schwarz 不等式，有 `|tr(K−I_{d})|≤√d‖K−I_{d}‖_{F}`。取 `K=A_{i}^{*}A_{i}`，得到 `tr(A_{i}^{*}A_{i})≥(1−a)d_{i}`。相加得 `tr Q≥(1−a)R>0`，从而 `D>0`。另外 `R′≥(1−δ)R≥3R/4>0`，且 `2e₀≤2(σ/2)²≤1/4`。

由迹的循环等式 `tr(XY)=tr(YX)`，每一对 `i,j` 有 `tr(A_{i} A_{i}^{*} A_{j} A_{j}^{*})=‖A_{i}^{*}A_{j}‖_{F}²`。展开即得

```text
tr(Q²)=∑_{i,j}‖A_{i}^{*}A_{j}‖_{F}².
```

对于 `i=j`，三角不等式给出 `‖A_{i}^{*}A_{i}‖_{F}≤(1+a)√d_{i}`。对于不同的指标用输入中的交叉项界。因 `1+η₀≥0`，把 `∑_{i≠j}d_{i} d_{j}` 放宽为 `R²`，再用 `D_{*}≤σR`，得到

```text
tr(Q²)≤(1+η₀)R²/D_{*}+(1+a)²R ≤ [1+η₀+(1+a)²σ] R²/D_{*}. (1)
```

把 `V_{i},V_{j}` 的列分别补成标准正交基。左乘 `V_{i}^{*}`、右乘 `V_{j}` 相当于对酉变换后的矩阵取一个子块。Frobenius 范数在酉变换下不变，取子块只会减少平方和。因此

```text
‖C_{i}^{*}C_{j}‖_{F}≤‖A_{i}^{*}A_{j}‖_{F}, tr(Q′²)≤tr(Q²).
```

同理，`C_{i}^{*}C_{i}−I_{r_{i}}=V_{i}^{*}(A_{i}^{*}A_{i}−I_{d_{i}})V_{i}`，其范数平方至多为 `e₀d_{i}`。求和后用 `R≤2R′`，就得到定理的第二条界。

## 第 3 节 · 只知道少掉几个维数，能保证留下多少迹？

写 `P_{i}=V_{i}V_{i}^{*}`，是到 `V_{i}` 的像的正交投影。由于 `tr(C_{i} C_{i}^{*})=tr(P_{i}A_{i}^{*}A_{i})`，第 `i` 块中损失的迹是

```text
tr[(I−P_{i})A_{i}^{*}A_{i}] =(d_{i}−r_{i})+tr[(I−P_{i})(A_{i}^{*}A_{i}−I)].
```

投影 `I−P_{i}` 的 Frobenius 范数为 `√(d_{i}−r_{i})`。用矩阵内积的 Cauchy–Schwarz 不等式，末项不超过 `√(d_{i}−r_{i})·a√d_{i}`。令 `L=R−R′`。对 `i` 求和，再用有限和的 Cauchy–Schwarz 不等式得到

```text
tr Q−tr Q′≤L+a√(LR)≤(δ+a√δ)R.
```

结合 `tr Q≥(1−a)R`，置 `t=√δ`，便有

```text
tr Q′≥(1−a−t²−at)R. (2)
```

因 `t≤1/2` 且 `a≤1/40`，右侧为正。换句话说，平方迹得到了上界，迹本身得到了下界，而且两个界都使用同一个原维数和 `R`。现在可以比较归一化的迹之比。

## 第 4 节 · 系数 5 和 3 怎样取得？

由（1）和 `D≤(1+η₁)D_{*}`，

```text
D tr(Q′²)≤(1+η₁)[1+η₀+(1+a)²σ]R².
```

括号里的各因子用 `η₀,η₁,a≤σ/2` 放大，得上界 `(1+σ/2)[1+σ/2+(1+σ/2)²σ]R²`。比较两个多项式可得

```text
(1+σ/2)[1+σ/2+(1+σ/2)²σ]≤(1+5σ)(1−σ/2)²≤(1+5σ)(1−a)².
```

第一步的右减左是 `2σ−(13/2)σ²+σ³/2−σ⁴/8≥0`，用 `0<σ≤1/20` 即可。第二步由 `a≤σ/2`。

再记 `b=1−a`、`v=t(t+a)`、`P=1+5σ+3t`。由于 `t≤1/2, a≤1/40, σ≤1/20`，

```text
2P(t+a)≤2·(11/4)·(21/40)=231/80≤3(1−a)=3b.
```

所以 `2Pbv≤3tb²`。展开 `P(b−v)²=Pb²−2Pbv+Pv²`，便得 `P(b−v)²≥(1+5σ)b²`。最后把它同（2）结合，

```text
D tr(Q′²) ≤ (1+5σ)b² R² ≤ P(b−v)² R² ≤ P(tr Q′)².
```

除以 `D>0`，得到定理的第一条界。

## 第 5 节 · 斜率不等式中的两个误差量

项目用 `η=5σ+3√δ`、`e=2e₀` 作为格斜率估计的两个输入。第一条迹界量化平均算子的特征值分布，因为对正半定矩阵 `Q′` 有 `tr(Q′²)≥(tr Q′)²/D`，两边接近时特征值接近均匀。第二条界约束每个块内部偏离等距的总量。这两个参数进入后面斜率式中的 `(η+4√e)H_{*}`。
