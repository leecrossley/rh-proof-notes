# 局部长度如何给出商格的两条斜率界？

## 第 1 节 · 命题 · 从局部长度和分歧权重到斜率

计数差证明用商格平均斜率的下界和最大斜率的上界。本篇说明，代码怎样将局部长度对这两种斜率的影响化成同一个组合 `G_{a}+F_{o}-E_{e}`，再把例外处的贡献吸收到下界的误差中。这里研究 `lower_bound_simplified` 和 `claimHigh_valid`，假设局部的长度公式与比较已经成立。[局部长与最大斜率公式的由来](%E5%B1%80%E9%83%A8%E9%95%BF%E5%BA%A6%E4%B8%8E%E6%95%B4%E9%99%A4%E6%80%8E%E6%A0%B7%E5%90%88%E6%88%90%E5%95%86%E6%A0%BC%E7%9A%84%E6%96%9C%E7%8E%87%E5%85%AC%E5%BC%8F.md)[两条斜率界在计数差证明中的位置](%E5%95%86%E6%A0%BC%E6%96%9C%E7%8E%87%E5%A6%82%E4%BD%95%E6%8E%A7%E5%88%B6%E8%AE%A1%E6%95%B0%E5%B7%AE.md)

固定有限处集 `W` 和有限提升指标集 `J`。给每个 `w∈W` 一个非负权重 `λ_{w}`。应用中它等于该处的对数权重乘分歧指数。给定实数 `g_{jw},F_{jw},E_{jw}` 和 `τ_w`，令

```text
s_{w}=∑_{j∈J}(g_{jw}+F_{jw}−E_{jw}),
G_{a}=2∑_{w∈W}λ_{w}(∑_{j∈J}g_{jw}−τ_w),
F_{o}=2∑_{w∈W}λ_{w}∑_{j∈J}F_{jw}, E_{e}=2∑_{w∈W}λ_{w}∑_{j∈J}E_{jw}.
```

这三个量加减后得到 `G_{a}+F_{o}−E_{e}=2∑_{w}λ_{w}(s_{w}−τ_w)`。记 `s′_{w}` 为实际斜率公式用到的局部值，`Δ_w≥0` 为局部额外损失的界，`L_{w}` 为用在长度公式中的数值，`W_{T}⊆W` 为需要另行估计的处集。在应用中，`W_{T}` 由剩余特征等于指定的整数 `T` 的处组成。

以 `μ_{M},μ_{M,1},μ_{N}` 分别记底格、中间格和目标商格的平均斜率。它们的最大斜率分别写作 `ν_M,ν_{M,1},ν_N`。下面只对这些实数的关系作推理。

**平均斜率下界。** 对所有满足第 2 节三组条件的数据，有

```text
μ_{N}≥μ_{M}+G_{a}+F_{o}−E_{e}−(4Q+L_{T}+R_{X}+1).
```

**最大斜率上界。** 若每个 `w∈W` 都有 `s′_{w}≤s_{w}`，并且 `ν_N≤ν_{M,1}+2∑_{w}λ_{w}(s′_{w}−τ_w)`、`ν_{M,1}≤ν_M`，则

```text
ν_N≤ν_M+G_{a}+F_{o}−E_{e}.
```

## 第 2 节 · 哪些局部量要控制？

给定实数 `d_{M},d_{u},δ,f,T,b,Q,P_{T},R_{d},L_{T},R_{X}`。以下是平均斜率下界所用的全部条件（`HypLow` 与 `HypLow2`）。

**一、秩与长度。** 有 `d_{M}>0,0≤δ<1,d_{u}=(1−δ)d_{M}`。若 `w∈W_{T}`，则 `τ_w=0`；若 `w∈W∖W_{T}`，则 `L_{w}≤d_{M}(τ_w+Δ_w)`。另有

```text
2∑_{w∈W_{T}}λ_{w} L_{w}/d_{u}≤P_{T}, 2∑_{w∈W}λ_{w}(s_{w}−s′_{w})≤R_{d}.
```

**二、平均斜率的局部公式。** 商格斜率由中间格斜率、各处变化和归一化长度给出。

```text
μ_{N}=μ_{M,1}+2∑_{w∈W}λ_{w}(s′_{w}−τ_w)−2∑_{w∈W}λ_{w}(L_{w}/d_{u}−τ_w).
```

**三、误差大小和中间格的斜率。** 写 `T_{a}=2∑_{w}λ_{w}τ_w`，要求每个 `τ_w≥0`，且

```text
δ≤2f/T≤1/2, T_{a}≤b², Q=∑_{w∈W}λ_{w}Δ_w, P_{T}≤L_{T}, R_{d}≤R_{X},
μ_{M,1}=μ_{M}−f [log(T−1)]/(T−2), 4fb²/T+f [log(T−1)]/(T−2)≤1.
```

在实际应用中 `T>2`，因而这几项是通常的实函数。原声明也允许按 Lean 的约定理解实数函数，除法的分母为零时商取 0，`log 0=0`，对 `u≠0` 取 `log u=log|u|`。证明只使用第三组列出的等式和不等式。

## 第 3 节 · 秩的变化怎样被吸收？

由于 `d_{u}=(1−δ)d_{M}>0`，对每个 `w∉W_{T}`，所给的长度界推出

```text
L_{w}/d_{u}−τ_w≤Δ_w/(1−δ)+[δ/(1−δ)]τ_w.
```

对 `w∈W_{T}`，由 `τ_w=0`，这些项的加权总和至多为 `P_{T}`。其余项求和后，用 `λ_{w},Δ_w,τ_w≥0` 把两类和都扩展到 `W`，得到

```text
2∑_{w∈W}λ_{w}(L_{w}/d_{u}−τ_w) ≤ P_{T} + 2Q/(1−δ)+[δ/(1−δ)]T_{a}.
```

由 `δ≤1/2`，有 `2Q/(1−δ)≤4Q`。又因为 `δ/(1−δ)≤2δ≤4f/T`，且 `T_{a}≤b²`，最后一项至多 `4fb²/T`。

将平均斜率等式里的 `s′_{w}` 换成 `s_{w}` 时，往下最多损失 `R_{d}`。因此

```text
μ_{N}≥μ_{M}+G_{a}+F_{o}−E_{e}−[4Q+P_{T}+R_{d}+4fb²/T+f [log(T−1)]/(T−2)].
```

方括号的后两项合计 ≤1，前面的两处专门误差分别由 `L_{T},R_{X}` 控制，得到平均斜率下界。最大斜率只需由 `s′_{w}≤s_{w}` 和 `λ_{w}≥0` 放大各局部贡献，再用 `ν_{M,1}≤ν_M`，便得最大斜率上界。

## 第 4 节 · 从局部数据到实际的商格条件

在 `slopesN_at_of` 的应用中，`Q` 是 `IOsum`。取工程中的统一常数 `C≥4` 后，由 `Q≥0` 有 `4Q≤CQ`。局部数据给出 `L_{T}≤C|T_{top}|m(a_{E}/k+b′)log T` 及 `R_{X}≤CX″`。于是这一篇的误差 `4Q+L_{T}+R_{X}+1` 被换成计数差证明中的 `L_{5}`。最大斜率的上界可以放宽 `CmB₀≥0`，以适配同一组数值条件。这里 `T_{top}` 是有限群中的顶点集合，和指定的整数 `T` 是两种量。
