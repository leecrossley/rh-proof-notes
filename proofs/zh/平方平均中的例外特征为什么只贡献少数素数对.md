# 平方平均中的例外特征为什么只贡献少数素数对

## 第 1 节 · 命题

给定 `m≥1`（`8∣m`）、`a∈ℕ`（`(a,m)=1`）、`Z∈ℝ`、`y≥0`、`η≥0`、`B∈ℝ`，以及任意 `κ:ℕ→ℂ` 满足 `|κ(n)|≤1`。令 `N=⌊Z⌋₊`，`P` 为满足 `q≡a (mod m)` 且 `q>N²` 的一个有限素数集。记 `c(n)=Λ(n)min(1,y/n)`（`n≥1`），其中 `Λ(pᵏ)=log p` 对 `k≥1`，其余为零。定义

```text
S(q)=∑_{1≤n≤N}c(n)κ(n)(n/q)， b_{p}=∑_{k≥1, pᵏ≤N}c(pᵏ)，
```

```text
R=∑_{pᵏ≤N, k≥1, 2∣k 或 p∣m}c(pᵏ)， L=∑_{1≤n≤N}c(n)。
```

这里 `(n/q)` 和下文的 `(q/s)` 是 Jacobi 符号。假设每个素数 `p` 都有 `b_{p}≤B`，并给定 `s_{*}∈ℕ`，使任意奇的无平方因子整数 `1<s≤N²`，只要 `(s,m)=1` 且 `s≠s_{*}`，就有 `|∑_{q∈P}(q/s)|≤η|P|`。

**结论。** `∑_{q∈P}|S(q)|² ≤ |P|(∑_{p≤N}b_{p}²+R²+2B²+2BR+ηL²)`。和式中 `p` 始终为素数。这是 `QH.meanSq_abs`。源代码把例外指标作为给定的自然数参数，应用时由单一例外定理选出它。

## 第 2 节 · 平方展开后只看模数之外的奇指数

平方展开后交换求和顺序。因为 `(n/q)` 是实数，且 `|κ(n)·\overline{κ(n′)}|≤1`，由三角不等式得

```text
∑_{q∈P}|S(q)|² ≤ ∑_{n,n′≤N} c(n)c(n′) |∑_{q∈P}(nn′/q)|。
```

给定 `n,n′≥1`，令 `s=s_{m}(nn′)=∏_{p∤m, vₚ(nn′) 为奇数}p`。因为 `q>N²`，没有任何 `q∈P` 整除 `nn′`，偶次幂因子在符号中全部消去。对于剩下的素数因子 `p`，在 `p∣m` 时，`(p/q)` 只由固定的 `q mod m` 决定。对 `p=2` 用平方互反律的补充公式，对奇 `p` 用互反律和 `4p` 中的两个模数 `4,p`。在 `p∤m` 时，`p` 是奇数，互反律把 `(p/q)` 化成固定符号乘 `(q/p)`。乘起来，得到对所有 `q∈P` 相同的符号 `σ=±1`，使得 `(nn′/q)=σ(q/s)`。

所以平方展开现在按 `s` 分类。若 `s>1` 且 `s≠s_{*}`，就可以使用假设中的抵消；这些对的总贡献至多 `η|P|L²`。其余对用逐项模长至多 1 的界。为避免 `s_{*}` 取值 0 或 1 的单独讨论，Lean 把两类剩余对标成 `s=1` 与 `s=max(s_{*},2)`。当 `max(s_{*},2)=2` 时，后一类为空，因为 `s` 必为奇数。

## 第 3 节 · 按两个素数幂的底数算例外项

现在只需考虑 `n=pᵏ,n′=qˡ`，其余权重为零。称一个素数幂属于集合 `E`，如果其指数为偶数或底数整除 `m`。这些幂的总权重正是 `R`。

如果 `s=1`，要么两个底数相同，贡献至多 `∑_{p}b_{p}²`；要么两个底数不同，各自都必须属于 `E`，贡献至多 `R²`。这给出了第一类的界。

固定 `s=r>1`。若 `r` 是素数，同底数的对必须都以 `r` 为底，权重总和至多 `b_{r}²`。不同底数的对中，一个以 `r` 为底，另一个属于 `E`，计入两个顺序，至多 `2b_{r}R`。若 `r` 合成，它必须是两个不同素数 `r=pq` 的乘积，两个底数也只能取这两个。否则这一类为空。因此合成情形的上界是 `2b_{p}b_{q}`。不论哪种情形，总权重都至多 `2B²+2BR`。乘上 `|P|`，再加一般项，得到命题。

## 第 4 节 · 把代数不等式用在素数窗口

**精确陈述。**存在绝对常数 `C>0`，使对每个 `0<ε≤1`、`K≥1`，可取 `Y₀≥3`。当 `Y≥Y₀` 时，对任何实数 `U` 及上面条件中的 `m,a`，假设

```text
(log Y)² log m/4 ≤ log U， Y^{ε/6} ≤ log U ≤ Y^{ε/5}(log Y)²，
```

并假设 `p∣m` 的素因子都满足 `p≤Y^{ε/5}` 或 `p>Y^{400K}`。令 `Z=Y^{400K}`，`P={q 素数 : √U<q≤U, q≡a (mod m)}`。则对每个 `y∈[Y,Y^{K}]`、每个 `|κ|≤1`，有 `∑_{q∈P}|S(q)|²≤C y log y |P|`。Lean 允许实数 `U≤0`，此时按集合定义无候选素数，结论自动成立。以下只需考虑 `U>0`。

这里用到的解析输入是 `twistK`。其陈述为对每个 `ε,A,D>0`，对充分大的 `Y` 及以上满足三个对数条件的 `U,m,a`，存在 `s_{*}∈ℕ`，使所有与 `m` 互素的奇无平方因子数 `1<s≤Y^{A}`，除了可能的 `s_{*}`，都满足 `|∑_{q∈P}(q/s)|≤Y^{−D}|P|`。取 `A=800K,D=K+1`，故任何 `s≤N²` 都落在该范围内。[单一例外定理的证明](%E9%9B%B6%E7%82%B9%E4%BE%8B%E5%A4%96%E4%B8%BA%E4%BB%80%E4%B9%88%E6%9C%80%E5%A4%9A%E5%BD%B1%E5%93%8D%E4%B8%80%E4%B8%AA%E4%BA%8C%E6%AC%A1%E6%89%AD%E6%9B%B2.md) 另因 `log U≥Y^{ε/6}`，对充分大的 `Y` 有 `Z²≤√U`。因此每个候选素数都大于 `N²`。

## 第 5 节 · 每个权重项为何恰好够小

下面用第一个 Chebyshev 上界 `ψ(t)=∑_{n≤t}Λ(n)≪t`。所有 `≪` 的乘法常数均为绝对常数。先对固定 `p` 求 `b_{p}`。当 `p≤y`，满足 `pᵏ≤y` 的部分至多 `log y`，剩余部分是几何尾和，至多 `2 log p≤2 log y`。当 `p>y≥3`，全部是尾和，`b_{p}≤2y log p/p≤2 log y`。故可以取 `B=3 log y`。

对于 `∑b_{p}²`，由 `π(t)≤√t+2ψ(t)/log t` 知 `π(y)≪y/log y`，故 `p≤y` 的部分为 `O(y log y)`。对 `p>y` 按 `2ʲ y<p≤2ʲ⁺¹y` 分段，使用 `b_{p}²≤4y²(log p)²/p²` 和 `∑_{p≤t}log p≤ψ(t)`，每段至多 `O(y 2^{−j}log(2ʲ⁺¹y))`。求和仍为 `O(y log y)`。

估计 `R` 时，偶次幂部分以 `n=u²` 求和，`Λ(u²)=Λ(u)`，所以是 `O(√y)`。具体来说，`u≤√y` 用 `ψ(√y)`，`u>√y` 按二倍区间求和，权重 `y/u²` 把各段压成 `O(2^{−j}√y)`。整除 `m` 的底数至多 `Y^{ε/5}≤y^{1/5}` 种，合计至多 `3y^{1/5}log y≪√y`。这给出 `R²+2B²+2BR≪y log y`。

最后，`L≤y∑_{n≤N}Λ(n)/n≪y log Z`，后一步也可按二倍区间使用 `ψ(t)≪t`。扩大只依赖于 `ε,K` 的 `Y₀`，使 `log Z=400K log Y≤√Y`。这样 `ηL²≪Y^{−(K+1)}y²Y≤y`，最后一步用 `y≤Y^{K}`。把四个权重界代回命题即得结论。[这个平均界怎样排除坏素数](%E5%B9%B3%E6%96%B9%E5%B9%B3%E5%9D%87%E6%80%8E%E6%A0%B7%E7%AD%9B%E6%8E%89%E5%8C%BA%E9%97%B4%E4%B8%8A%E7%9A%84%E5%9D%8F%E7%B4%A0%E6%95%B0.md)
