# 相对误差怎样从素数幂传到素数计数

## 第 1 节 · 命题

给定 `X≥16`、`0≤K≤1`、`|θ|≤1`、`1/2≤β≤1`、`D≥0`。系数 `c(n)` 实值，且对所有正整数 `n` 满足 `0≤c(n)≤Λ(n)`。令 `Ψ(t)=∑_{n≤t}c(n)`。假设每个 `t∈[√X,X]` 都满足

```text
|Ψ(t)−F(t)|≤Dt， F(t)=K(t−θ t^{β}/β)。
```

记 `Li(Y)=∫₂^{Y}dt/log t`。则

```text
|∑_{2≤n≤X}c(n)/log n − K(Li(X)−θLi(X^{β}))| ≤ 5DX/log X + 40√X。
```

这是 `abel_core`。系数 `c(n)` 后面取算术级数上的 von Mangoldt 权重。证明还说明，在有例外实零点时，误差为什么依旧可以写成相对于实际主项的误差。

## 第 2 节 · Abel 求和把两个主项同时换成对数积分

令 `s=√X`。对 `s<n≤X` 以函数 `1/log t` 作 Abel 求和，式子为

```text
∑_{s<n≤X}c(n)/log n=Ψ(X)/log X−Ψ(s)/log s+∫_{s}^{X} Ψ(t)/(t log²t) dt。
```

另一方面，若 `M(t)=K(Li(t)−θLi(t^{β}))`，则 `M′(t)=F′(t)/log t`。因此 `M(X)−M(s)` 也有同样的表达式，把 `Ψ` 换成 `F` 即可。相减后，`X` 处的端点误差不超过 `DX/log X`。在 `[s,X]` 上，`log t≥(log X)/2`，故积分误差不超过 `4DX/(log X)²≤4DX/log X`。

小尺度用 Chebyshev 界 `∑_{n≤t}Λ(n)≤6t`。因为 `log n≥log 2≥1/2`，所以 `0≤∑_{2≤n≤s}c(n)/log n≤12s`。由于 `2≤s^{β}≤s`，有 `|M(s)|≤2Li(s)≤4s`。还因 `|F(s)|≤3s` 且 `log s≥1`，`s` 处的端点差至多 `9s`。所以小尺度总误差至多 `25s≤40s`。这给出了命题。

## 第 3 节 · 主项也有一个与例外零点距离成正比的下界

设模数 `M₀≥8` 是 8 的倍数，`b` 与 `M₀` 互素。把 `c(n)` 取为 `Λ(n)` 乘以 `n≡b (mod M₀)` 的示性函数。算术级数上的特征正交关系给出相应的 `Ψ(t)` 为全部模 `M₀` 特征的扭曲 Chebyshev 和乘权平均。若存在例外特征 `ξ` 和零点 `β`，其主项恰好以 `K=1/φ(M₀),θ=ξ(b)` 代入上式，`ξ(b)` 是实数。没有例外特征时令 `θ=0,β=1`。

记 `L=log X`，并设 `L≥16 log M₀`。对于相对的 Chebyshev 估计，令 `η=1`（无例外）或 `η=min(1,(1−β)log M₀)`（有例外）。`etaOf_lower` 给出 `η≥c₁/M₀`，其中 `c₁>0` 是有效绝对常数。此处要证明

```text
Li(X)−θLi(X^{β})≥η X/(2L)。
```

若 `θ≤0`，左端至少为 `Li(X)≥(X−2)/L≥X/(2L)`。若 `θ>0`，则 `η≤(1−β)L`，所以 `X−X^{β}=X(1−e^{−(1−β)L})≥X(1−e^{−η})≥η X/2`。最后一步在 `0≤η≤1` 上由指数函数的凸性得到。由 `θ≤1` 和在 `[X^{β},X]` 积分，左端至少为 `(X−X^{β})/L`，因此得证。

## 第 4 节 · 零点造成的主项缩小由同一个比例因子补偿

**解析输入。**对每个 `M₀≥8`（`8∣M₀`），固定上面意义下的可选例外对。记 `Ψ_{χ}(t)=∑_{n≤t}Λ(n)χ(n)`，主项 `A_{χ}(t)` 为平凡特征时的 `t`，例外特征时的 `−t^{β}/β`，其余为零。假设存在绝对 `A>0,c>0,C₀`，使当 `t≥2`、`log t≥C₀ log M₀ log(log M₀+2)` 时，

```text
∑_{χ mod M₀}|Ψ_{χ}(t)−A_{χ}(t)|≤A t η (exp(−c log t/log M₀)+exp(−c √(log t)))。
```

这是 `PsiRel` 的估计，源码由两段关于模数与 `log t` 相对大小的定理合成。选 `log X≥max(16,2C₀) log M₀ log(log M₀+2)`，则任意 `t∈[√X,X]` 落在它的适用范围。取 `c′=min(c/2,c²/2)`，记 `E(X)=exp(−c′L/log M₀)+exp(−√(c′L))`。正交关系后误差至多 `Aη E(X)t/φ(M₀)`，故在第一节命题中取 `D=Aη E(X)/φ(M₀)`。

把 `c(n)/log n` 的和换成真正的素数计数，丢掉的是指数至少为 2 的素数幂，每项权重 `1/k`。其总数至多 `√X log X/log 2`，足以得到源码的 `4√X log X` 上界。于是误差分成 `5Aη E(X)X/(φ(M₀)L)` 和至多 `44√X L` 的余量。前者由主项下界直接转成至多主项的 `10AE(X)` 倍。后者也可吸收，因为 `η≥c₁/M₀`、`φ(M₀)≤M₀`、`M₀²≤X^{1/8}`，且 `E(X)≥e^{−√(c′L)}`。把余量除以主项下界再除以 `E(X)`，至多是绝对常数乘 `L² exp(−3L/8+√(c′L))`，它有界。故得到以 `E(X)` 为比例的相对素数计数误差。[相对素数计数怎样用于二次扭曲](%E9%9B%B6%E7%82%B9%E4%BE%8B%E5%A4%96%E4%B8%BA%E4%BB%80%E4%B9%88%E6%9C%80%E5%A4%9A%E5%BD%B1%E5%93%8D%E4%B8%80%E4%B8%AA%E4%BA%8C%E6%AC%A1%E6%89%AD%E6%9B%B2.md)
