# 局部指数取整的误差为何可控？

## 第 1 节 · 命题 · 从整数指数到连续估计

格有真正的整数指数，而主项用的是连续的实数权重。源码的 `LinkMu` 比较这两者。本篇解释为什么做一次取整后，误差只同**出现过的有理素数**有关，并且可以用窗口尺度统一控制。[斜率改变量的精确公式](%E5%B1%80%E9%83%A8%E9%95%BF%E5%BA%A6%E6%80%8E%E6%A0%B7%E6%94%B9%E5%8F%98%E6%A0%BC%E7%9A%84%E5%B9%B3%E5%9D%87%E4%B8%8E%E6%9C%80%E5%A4%A7%E6%96%9C%E7%8E%87.md)

固定全虚数域 `K`，取有限素理想集 `S`，写 `p_{w}`、`e_{w}`、`f_{w}` 为 `w∈S` 的剩余特征、分歧指数和剩余次数。记 `λ_{w}=log(Nw)/[K:ℚ]=f_{w} log(p_{w})/[K:ℚ]`。给每个 `w∈S` 指定实数 `g_{w}`，并取非零有限生成格 `M`。置

```text
I=∏_{w∈S}w^{−⌊e_{w}g_{w}⌋}, U=2∑_{w∈S}λ_{w}e_{w}g_{w}.
```

本篇把 `M` 换成 `IM`，记误差为 `E=|μ(IM)−μ(M)−U|`。沿用前篇的斜率归一化和固定的度量。

**命题。** 给定非负实数 `X″`，素数 `T,g_{0},g_{1},d`，以及正整数 `D_Γ`。假设只要 `g_{w}≠0`，就有 `p_{w}≤X″`，或 `p_{w}` 属于这四个素数，或 `p_{w}∣D_Γ`。那么

```text
E≤2[X″ log 4+log T+log g_{0}+log g_{1}+log d+log D_{Γ}]. (1)
```

若还有 `log g_{0},log g_{1},log d≤X″`、`log T≤C_{T}X″` 以及 `log D_Γ≤C_Γ X″`，则

```text
E≤2(log 4+3+C_{T}+C_{Γ})X″. (2)
```

## 第 2 节 · 怎样避免按数域次数重复收费？

由前篇分式理想缩放公式，`μ(IM)−μ(M)=2∑_{w}λ_{w}⌊e_{wg}_w⌋`。若 `g_{w}=0`，第 `w` 项无误差。其余地方的取整误差介于 −1 与 0 之间。所以

```text
E ≤ 2∑_{w∈S，g_{w}≠0}λ_{w}.
```

现在按 `p_{w}=p` 把这组地方分组。由于 `λ_{w}≥0`、`e_{w}≥1`，有

```text
∑_{w∣p 且入选}λ_{w} ≤∑_{w∣p} e_{w}λ_{w} = (log p)/[K:ℚ]·∑_{w∣p}e_{w}f_{w} =log p.
```

最后一步是素理想分解的次数公式。于是每个出现的有理素数只需付一次 `log p`。

对小素数使用 `∑_{p≤Y}log p≤Y log 4`。这个初等界可从二项式系数得到。令 `P(N)=∏_{p≤N}p`。若 `N=2k`，区间 `(k,2k]` 中的素数乘积整除 `binom(2k,k)≤4^{k}`。若 `N=2k+1` 且 `k≥1`，则 `(k+1,2k+1]` 的乘积整除 `binom(2k+1,k)`。后一个系数和 `binom(2k+1,k+1)` 相等，所以各自 ≤ `2^{2k}=4^{k}`。两种情况下归纳即得 `P(N)≤4^{N}`，对实数 `Y≥0` 再取整。

四个例外素数的权重用各自对数相加。`D_Γ` 的互异素因子乘积整除 `D_Γ`，它们的对数和至多为 `log D_Γ`。同一个素数若属于两类，重复加仍给出上界。因此（1）成立，将假设中的五项对数大小代入就得（2）。

## 第 3 节 · 为什么例外项的对数也被同一尺度吸收？

实际数据对每个字 `u` 使用 `g_{w}=sg(u,w)`，它是每个提升指标的“增量加修正减损失”之和。对于大于 `X″` 且不属于四个例外、也不整除 `D_Γ` 的素数，`ZeroAbove` 令增量和损失为零，记录中的 `F_above` 又令修正为零。因此 `sg(u,w)=0`，给出命题所需的支集条件。[局部增量的支集条件](https://github.com/tamnd/riemann-lean/blob/9110120cdc195ee8d2fb08d2adac8b1747912d8f/lean/src/Formalism/LocalRingCardinality/DataParams%E2%82%82.lean)

这里 `x>1,0<ε<1/52`，`X′=exp(x^{ε/3})`、`X″=X′xn_{H}`，其中 `n_{H}≥1` 是群的阶，`f=2n_{H}`。尺度条件给出 `log g_{i}≤x^{ε+ε/100}`、`log d≤x^{ε/5+ε/100}`。各指数 ≤1，而 `x≤X″`，故这三项分别 ≤ `X″`。

对 `T`，族的条件统一给出 `log T≤C_{T}^{0} m x^ε`。因为 `ε>0` 固定，可取足够大的阈值使 `C_{T}^{0}≤x^{ε/100}`。又 `m≤2n_{H}`，所以 `log T≤2xn_{H}≤2X″`。这对应 `muTu_of_tuSize`。

对 `D_Γ`，族的条件为 `log D_Γ≤C f N(m) log(fN(m))`。工程取 `N(m)=k+m(t+1)`。尺度条件给出 `N(m)≤η_{sz}≤exp(x^{ε/4})≤X′` 和 `n_{H}≤x³`，故

```text
log(fN(m))≤log 2+3 log x+x≤4x,
fN(m)log(fN(m))≤(2n_{H} X′)(4x)=8X″.
```

源码放宽最后的常数为 10。用 `|C|` 放大原常数，就得到 `log D_Γ≤10|C|X″`，对应 `muDGam_of_fact`。

取长度消失、满秩、有限生成和两条族大小条件的各个阈值的最大值。对每个更大的 `x`、每个候选、每个字，公式（2）都可用。这就是 `LinkMu` 所需的统一量词。

## 第 4 节 · 本篇补齐的是哪一项？

在平均斜率的下界中，局部项 `g_{w}` 要换成乘分式理想所用的 `g′_{w}=⌊e_{wg}_w⌋/e_{w}`。本篇控制 `2∑_{w} e_{w}λ_{w}(g_{w}−g′_{w})`。因此可以在先前的商格证明中取 `R_{d}≤C X″`，这正是那一篇由舍入引入的误差。[舍入误差的使用处](%E5%B1%80%E9%83%A8%E9%95%BF%E5%BA%A6%E5%A6%82%E4%BD%95%E7%BB%99%E5%87%BA%E5%95%86%E6%A0%BC%E7%9A%84%E4%B8%A4%E6%9D%A1%E6%96%9C%E7%8E%87%E7%95%8C.md)

- `mu_diff`、`round_le`（第 380、401 行）给出精确改变量与按地方计算的误差。按有理素数分组是 `sum_lwP_le`、`sum_lwP_le_primes`。[SumLogPrimeFactorsLe.lean](https://github.com/tamnd/riemann-lean/blob/9110120cdc195ee8d2fb08d2adac8b1747912d8f/lean/src/Formalism/SharpRestriction/AdmissibleParameterJoins/SumLogPrimeFactorsLe.lean)
- `sg_eq_zero` 和 `nprimeMu_at` 给出支集和（1）。`nprimeMuR_at` 用统一的大小条件得到（2），`linkMu`（第 728 行）统一候选和阈值。[SumLogPrimeFactorsLe.lean](https://github.com/tamnd/riemann-lean/blob/9110120cdc195ee8d2fb08d2adac8b1747912d8f/lean/src/Formalism/SharpRestriction/AdmissibleParameterJoins/SumLogPrimeFactorsLe.lean)
- `muTu_of_tuSize` 与 `muDGam_of_fact` 统一特殊整数的大小，`linkMu_of_linkDIV`（第 775 行）从全局整除数据取出支集条件，再调用这一证明。[MuTuOfTuSize.lean](https://github.com/tamnd/riemann-lean/blob/9110120cdc195ee8d2fb08d2adac8b1747912d8f/lean/src/Formalism/SharpRestriction/MuTuOfTuSize.lean) · [SumLogPrimeFactorsLe.lean](https://github.com/tamnd/riemann-lean/blob/9110120cdc195ee8d2fb08d2adac8b1747912d8f/lean/src/Formalism/SharpRestriction/AdmissibleParameterJoins/SumLogPrimeFactorsLe.lean)
