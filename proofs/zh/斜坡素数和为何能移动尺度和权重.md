# 斜坡素数和为何能移动尺度和权重

## 第 1 节 · 命题 · 两种移动估计

证明逐点上界时，先把权重 `w` 换成统一的参考值，再把素数和的参数 `a/w` 换成目标点 `x`。两个操作用到的估计不同。本篇从斜坡函数的定义出发证明这两条估计。[两条界的使用位置](%E5%B9%B3%E7%A7%BB%E5%B9%B3%E5%9D%87%E5%A6%82%E4%BD%95%E7%BB%99%E5%87%BA%E7%B4%A0%E6%95%B0%E5%92%8C%E7%9A%84%E9%80%90%E7%82%B9%E4%BC%B0%E8%AE%A1.md)

取任意有限交换群 `H`，令 `A=(ℤ/2ℤ)²×H`；对每个素数给出子群 `I_{p}≤A` 和元素 `F_{p}∈A`，再给任意函数 `ℓ:Â→ℂ`。这里 `Â` 是所有复值群特征，平凡特征记为 `1`。令 `P_{ψ}(n)` 是惯性陪集平均的乘积，令 `c_{ψ}(n)=Λ(n)P_{ψ}(n)`。写 `h_{+}=max(h,0)`。对正实数 `y`，定义

```text
U_{ψ}(y)=∑_{n≥1}c_{ψ}(n)(y/n−1)_{+},
G_{ψ}(y)=U_{ψ}(y)+yℓ(ψ) (ψ≠1),
G_{1}(y)=U_{1}(y)−y log y+(1+γ_{E})y.
```

求和实际上只到 `⌊y⌋`。`Λ(n)` 在 `n=p^{k}`（`k≥1`）时为 `log p`，其余为零。`γ_{E}` 是欧拉常数。`P_{ψ}` 的定义见计数恒等式的第 1 节。本篇允许任意上述局部数据与任意 `ℓ`。

**定理一。** 对所有 `ψ` 和正实数 `a,w,w′`，

```text
|wG_{ψ}(a/w)−w′G_{ψ}(a/w′)| ≤ 3a |w−w′| / min(w,w′).
```

**定理二。** 存在绝对常数 `C_{d}≥0`，使对所有上述群和局部数据及一切 `y,z≥1`，有

```text
|G_{ψ}(y)−G_{ψ}(z)| ≤ |y−z|[log max(y,z)+C_{d}+|ℓ(ψ)|] (ψ≠1),
|G_{1}(y)−G_{1}(z)| ≤ C_{d}|y−z|.
```

## 第 2 节 · 为什么会出现 log y？

先记 `Ψ(Y)=∑_{1≤n≤Y}Λ(n)`。我们要用 `Ψ(Y)≤3Y`（`Y≥0`）。Lean 从 mathlib 的 Chebyshev 界 `Ψ(Y)≤(log 4)Y+2√Y log Y`（`Y≥1`）推出这一步，因为 `log u≤u/e`，且 `log 4+4/e<3`。也可以直接用下列二项式系数论证得到所需的 `3Y` 界。

对整数 `m≥1`，中心二项式系数 `C(2m,m)` 的 `p` 进指数等于 `∑_{j≥1}(⌊2m/p^{j}⌋−2⌊m/p^{j}⌋)`。每一项非负，而 `m<p^{j}≤2m` 时该项等于 1。因此

```text
Ψ(2m)−Ψ(m)≤log C(2m,m)≤2m log 2.
```

后一界来自二项式系数之和为 `2^{2m}`。从 `m=1,2,4,…,2^{k−1}` 相加，得 `Ψ(2^{k})≤(2^{k+1}−2)log 2`。若 `Y≥1`，取最小的 `2^{k}≥Y`，便有 `Ψ(Y)≤4Y log 2≤3Y`。当 `0≤Y<1` 时和为零。

令 `A(k)=∑_{1≤n≤k}Λ(n)/n`。恒等式 `log n=∑_{d∣n}Λ(d)` 可由素因数分解直接读出。把它对 `n≤k` 求和再交换求和，因为 `d` 的倍数有 `⌊k/d⌋` 个，得到

```text
log k! = ∑_{1≤d≤k}Λ(d)⌊k/d⌋.
```

因此 `0≤kA(k)−log k!≤Ψ(k)`。另一方面，`∫_{1}^{k}log u du≤log k!≤k log k`，左界来自 `log` 单调。两边除以 `k≥1`，得到源码所用的界

```text
log k−1≤A(k)≤log k+log 4+4.
```

上界用 `Ψ(k)≤3k≤(log 4+4)k` 即可。这里分析的是每条斜坡对参数的变化率，所以累加的是 `Λ(n)/n`。

## 第 3 节 · 平凡项为何能去掉 log y？

每个群特征的取值是单位根，因此惯性陪集中的平均值的模至多 1。将这些平均值相乘得 `|P_{ψ}(n)|≤1`，故 `|c_{ψ}(n)|≤Λ(n)`。又因为取正部是 `1`–Lipschitz，

```text
|(y/n−1)_{+}−(z/n−1)_{+}|≤|y−z|/n.
```

若 `ψ≠1`，在两个和中用同一上限 `k=⌊max(y,z)⌋`，用三角不等式及主项的差得

```text
|G_{ψ}(y)−G_{ψ}(z)|≤|y−z|[A(k)+|ℓ(ψ)|].
```

由于 `k≥1`，用上一页的上界以及 `log k≤log max(y,z)` 即得所求。

对于平凡特征，在整个闭区间 `[k,k+1]` 上可以只求和到整数 `k`。右端点新增的一项斜坡值为零。因此在这段区间上

```text
G_{1}(y)=yA(k)−∑_{n≤k}Λ(n)−y log y+(1+γ_{E})y.
```

这个表示式在区间内部的导数为 `A(k)−log y+γ_{E}`。由于 `k≤y≤k+1≤2k`，且 `½<γ_{E}<⅔`，上节中 `A(k)` 的两边界给出导数的绝对值最多 `K₀=log 4+7`。减去的主项使 `log k` 与 `log y` 抵消到常数精度。由中值定理，`G₁` 在这个闭区间上以 `K₀` 为 Lipschitz 常数。

把任意两个 ≥1 的参数之间的区间在各整数处分割。对小区间的估计求和，长度恰好加回总长度，所以同一 `K₀` 适用于两个参数。取 `C_{d}≥max{log 4+4,K₀}` 即可同时覆盖两类特征。Lean 的通用构造还使用了延伸到 `y≥½` 的同类估计，`½≤y≤1` 时直接对主项求导即可。

## 第 4 节 · 权重在正部函数里怎样变化？

固定 `a,w,w′>0`，由对称性设 `w≤w′`。把两个斜坡和统一截在 `⌊a/w⌋`。利用 `w(a/(wn)−1)_{+}=(a/n−w)_{+}`，加权素数和的差是

```text
S=∑_{n≤a/w}c_{ψ}(n)[(a/n−w)_{+}−(a/n−w′)_{+}].
```

方括号中的数介于 0 和 `w′−w` 之间。故 `|S|≤Ψ(a/w)(w′−w)≤3(a/w)(w′−w)`。若 `ψ≠1`，加权修正项两次都是 `aℓ(ψ)`，相消后只留下 `S`。

若 `ψ=1`，则 `c_{1}(n)=Λ(n)≥0`，所以 `0≤S≤3(a/w)(w′−w)`。主项的线性部分也相消，对数部分则使实际差等于 `S−a log(w′/w)`。由 `log u≤u−1` 得

```text
0≤a log(w′/w)≤(a/w)(w′−w).
```

因而二者相减的绝对值仍在 `3(a/w)(w′−w)` 以内。一般顺序下，即为以 `min(w,w′)` 作分母的界。
